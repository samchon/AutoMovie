# 공간 문장의 반복과 호흡

전 모집단은 저택 공간 한 단위다. 좌표 표기는 배치 재현을 위한 공통 형식이며, 보존 문장은 현재 모델 값과 사용자 고정 구성을 설명한다. 방별 목록은 서로 다른 생활 물품을 남기고 같은 검사 결론을 반복하지 않는다.

## 문장 호흡의 분포 {#surface-cadence-distribution}
<!--

@evidenceReview obligations/core/defaults.md#surface-cadence-distribution #f287e18 앞의 층별 구성은 방향과 연결을 풀어 쓰고 홀·계단은 짧은 수치 절을 이어 배치를 재현한다. 외관·정원과 관찰 구간은 언제 추가 시점이 필요한지 조건을 설명하므로 모든 문단을 동일한 길이의 절차로 맞추지 않는다.
@evidence spaces/001-manor.md#manor-space 층별 구성에서 물품 배치, 상층·계단, 외관과 관찰로 설명 압력이 이동한다.

좌표를 연속으로 읽는 홀·계단과 방향·용도를 설명하는 층별 구성이 다른 호흡을 가진다. 네 굵은 표지는 같은 H2 안의 읽기 구간을 나누며 독립된 검사나 새 조건을 만들지 않는다.
