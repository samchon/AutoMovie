# 관찰, 주장과 사람의 판단

## 관찰과 주장의 분리 {#evidence-observations-and-claims}

Evidence는 직접 관찰하거나 측정한 결과, 그 결과에서 도출한 claim, 자동 판정과 사람의 judgment를 서로 다른 기록으로 구분하고, 각 claim과 judgment가 의존한 observation을 추적할 수 있게 해야 한다.

### 직접 관찰의 조건 {#evidence-observation-conditions}

Observation은 관찰한 대상과 revision, 시간 또는 frame 구간, view나 channel, 측정 단위, 관찰 방법, 실행 조건과 실제 결과를 기록해야 하며, 보이지 않거나 측정하지 않은 내용을 관찰 사실로 채워서는 안 된다.

### 주장과 해석의 근거 {#evidence-claim-basis}

Claim은 주장한 내용, 적용 범위, 근거 observation과 derivation, 가정, 불확실성과 반증 조건을 식별해야 하며, source의 존재나 signature의 유효성만으로 source가 말하는 내용의 진실을 자동 확정해서는 안 된다.

### 자동 판정의 경계 {#evidence-automated-finding-boundary}

자동 검사는 입력, 규칙 또는 기준의 identity, 실제 결과와 pass, fail, warning, unsupported 또는 not-run 상태를 분리해 보여야 하며, 설명이나 심각도 추정치를 측정 결과 자체로 표시해서는 안 된다.

### 사람 판단의 이력 {#evidence-human-judgment-history}

사람의 승인, 거부, 예외 허용, 미학적 평가와 사실 확인은 판단자 또는 승인된 가명, 역할과 권한, 판단 시점, rubric 또는 질문, 검토한 evidence identity, 결정과 이유를 기록해야 하며, 뒤의 판단은 앞의 판단을 덮어쓰지 않고 supersede 관계로 이어져야 한다.

### 이견과 판정 변경 {#evidence-disagreement-and-resolution}

서로 충돌하는 observation, claim 또는 judgment는 하나를 조용히 삭제하지 않고 함께 보존해야 하며, 사용자는 어느 기록이 current 판정인지, 누가 어떤 추가 근거로 이견을 해소했는지 또는 미해결로 남겼는지 확인할 수 있어야 한다.
