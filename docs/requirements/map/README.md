# 맵과 세계 요구사항

맵은 영화 속 건물, 인물과 사건이 놓이는 광역 세계를 소유한다. 배경용 그림이 아니라 지형, 수계, 식생, 공공 공간, 교통, 토지 이용, 기반시설, 날씨와 시간 변화가 같은 좌표와 identity로 상호작용하는 공간이다.

이 요구사항은 현실의 어느 지역과 시대, 가상 세계와 양식화된 장르에도 적용되는 일반 능력을 다룬다. 저장소가 특정 역사 지도, 정착지 kit, 도로 규격, 식생 목록이나 완성된 지형 content를 미리 제공한다는 뜻이 아니며, project가 선택한 자료와 저작 규칙으로 필요한 세계를 만들고 검증할 수 있어야 한다.
