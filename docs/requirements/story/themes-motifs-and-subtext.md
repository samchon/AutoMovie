# 주제, Motif와 Subtext

## 반복되는 의미의 추적 {#story-themes-motifs-subtext}

Theme, motif, visual 또는 sonic rhyme, symbol와 subtext를 작품의 해석 가능한 의도로 기록하고 구체적인 scene, event, object, composition 또는 sound와 연결할 수 있어야 한다.

Theme statement는 작품이 제기하는 질문, 서로 충돌하는 관점, 변화 방향 또는 의도된 ambiguity를 표현할 수 있어야 한다. 단일 교훈 문장만을 모든 작품에 요구하지 않아야 한다.

### 강제 해석의 금지 {#story-theme-interpretation-boundary}

Theme는 관객의 유일한 해석을 강제하거나 geometry와 camera를 자동 선택하는 명령이 아니며 production이 채택한 observable realization만 추적해야 한다.

관객 해석, 저자의 의도, 인물의 믿음과 마케팅 문구를 서로 다른 statement로 구분할 수 있어야 한다. 검토자는 의도가 전달되는지 판단할 수 있지만 의미에 대한 유일한 정답을 evidence로 위조하지 않아야 한다.

### Motif 변주 {#story-motif-variation}

같은 motif가 반복, 반전, 생략, 재맥락화와 climax에서 어떻게 달라지는지 identity와 occurrence를 통해 비교할 수 있어야 한다.

Motif identity는 특정 prop, 색, melody 또는 camera device에 묶이지 않고 여러 매체의 realization을 가질 수 있어야 한다. 한 realization을 교체해도 motif의 story role과 occurrence 관계가 보존되어야 한다.

### Subtext와 Performance {#story-subtext-performance}

말과 의도가 다른 순간은 actor goal, reaction, blocking, framing와 sound가 표현할 수 있는 cue로 내려가야 하며 설명문만으로 구현되었다고 주장하지 않아야 한다.

Subtext는 누가 무엇을 숨기거나 원하는지, 관객이 언제 알아차릴 수 있는지와 오독 가능성을 표현할 수 있어야 한다. Actor performance, staging와 edit은 표현 방식을 소유하며 theme 문서가 세부 gesture를 자동 지시하지 않아야 한다.

### Coverage {#story-theme-coverage}

핵심 theme와 motif가 어느 장면에도 나타나지 않거나 상위 이야기 약속 없이 장식적으로 추가된 경우 검토 가능한 gap으로 남겨야 한다.

### Theme의 진행과 Counterpoint {#story-theme-progression-counterpoint}

Theme는 setup, challenge, counterexample, reversal와 resolution 또는 의도된 미해결을 scene과 event에 연결할 수 있어야 한다. 서로 충돌하는 theme와 character viewpoint를 하나의 평균적인 메시지로 합치지 않아야 한다.

### Symbol의 Source와 문화 맥락 {#story-symbol-source-context}

외부 문화, 역사, 종교 또는 실제 공동체의 symbol과 motif를 사용할 때 source, 의미 범위, 불확실성, 승인 또는 검토 필요와 project의 재해석을 구분할 수 있어야 한다. 생성 도구가 익숙한 상징을 자동 삽입하고 보편적 의미라고 주장하지 않아야 한다.

### 의도적 부재와 절제 {#story-motif-absence-restraint}

Motif를 사용하지 않거나 예상 지점에서 생략하는 선택도 occurrence 관계의 일부로 기록할 수 있어야 한다. Coverage는 모든 scene에 motif를 반복하도록 강제하지 않고 선택된 출현과 부재가 의도된 진행에 답하는지 판정해야 한다.

### Theme 변경 영향 {#story-theme-change-impact}

Theme statement, motif identity 또는 subtext intent의 변경은 관련 scene, dialogue, production design, sound, edit와 review target을 식별할 수 있어야 한다. 표현 하나의 변경이 theme 전체를 바꾼 것으로 과장하거나 theme 변경을 장식 수정으로 축소하지 않아야 한다.

### Theme Acceptance 경계 {#story-theme-acceptance-boundary}

Theme acceptance는 필수 occurrence, 대비, payoff와 observable realization의 존재를 판정할 수 있으나 관객 감정을 하나의 수치나 해석으로 강제하지 않아야 한다. 사람의 판단이 필요한 항목과 구조적으로 확인 가능한 coverage를 분리해야 한다.
