# 시대와 양식의 자유

## 시대에 종속되지 않는 표현 {#asset-era-independent-expression}

고대, 중세, 근대, 현대, 미래와 가상 세계의 자산을 같은 보편 기하·재료·관계·pattern·state 능력으로 구성할 수 있어야 한다.

### 양식은 입력이다 {#asset-style-as-input}

비례, silhouette, 제작 방식, 장식, 마감, 손상과 색채가 시대와 양식을 표현하며 engine의 고정된 style 목록이 가능한 결과를 제한해서는 안 된다.

### Reference의 역할 {#asset-style-reference-role}

Image, drawing, text와 치수 reference는 저자가 형상과 material을 만드는 근거가 될 수 있지만 reference 자체가 검증되지 않은 geometry나 history fact를 자동으로 확정하지 않는다.

### 혼합과 예외 {#asset-style-mixing}

한 작품이나 asset 안에서 여러 시대, 지역과 fictional style을 의도적으로 혼합할 수 있어야 하며 이를 오류로 취급하지 않는다.

### 완성 양식 catalogue의 거부 {#asset-style-catalogue-refusal}

저장소는 특정 시대의 완성 ornament, uniform, furniture와 building set을 일반 능력인 것처럼 제공하지 않는다.
