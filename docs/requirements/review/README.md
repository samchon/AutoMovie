# 검토 요구사항

검토는 제품 사용자가 deterministic blocking pass의 staging, motion, timing, continuity와 전달 상태, 그리고 작품이 담고 있는 주체를 직접 확인하고 제작 결정을 내리는 과정이다. 검토 결과는 무엇을 보았는지, 어떤 기준과 비교했는지, 누가 어떤 범위에 판정했는지를 재현 가능하게 남겨야 한다.
