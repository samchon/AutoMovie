# Alternative Take와 Version 비교

## 후보 사이의 근거 있는 선택 {#review-alternative-takes-versions}

여러 take, edit, render, repaint rendition 또는 delivery version을 공통 의도와 source에 비추어 비교하고 선택 이유와 선택되지 않은 후보의 상태를 보존할 수 있어야 한다.

### 공통 Basis와 Difference {#review-alternative-common-basis-difference}

비교는 후보의 공통 source와 의도, 달라진 performance, staging, camera, timing, edit, style, quality 또는 delivery 조건을 구분하여 어떤 차이가 판정에 기여했는지 보여야 한다.

### 동기화된 비교 {#review-synchronized-comparison}

후보를 같은 semantic event, frame 또는 time range와 가능한 한 같은 presentation 조건에서 직접 비교할 수 있어야 하며 길이나 구조가 달라 대응하지 않는 구간을 임의로 같은 순간처럼 취급하지 않아야 한다.

### 후보별 Finding과 판정 {#review-candidate-specific-findings}

각 후보의 주석, Finding, 검토 coverage와 판정을 독립적으로 유지하고 한 후보의 통과나 결함을 다른 후보에 적용하지 않아야 한다.

### 선택과 보류 {#review-alternative-selection}

Selected, alternate, hold, rejected와 superseded를 구분하고 선택자는 기준, tradeoff와 관련 Finding을 근거로 남겨야 한다.

### 비교 이력 {#review-comparison-history}

새 version이 추가되거나 선택이 바뀌어도 이전 비교의 대상, 결과와 이유를 보존하고 현재 선택과 과거 선택을 구분할 수 있어야 한다.
