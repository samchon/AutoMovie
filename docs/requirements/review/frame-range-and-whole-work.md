# Frame, 구간과 전체 작품 검토

## 서로 다른 검토 단위의 보존 {#review-frame-range-whole-work}

Frame, 시간 구간과 전체 작품 검토는 서로 다른 질문에 답하며 각 결과와 coverage를 독립적으로 보존해야 한다.

### Frame 검토 {#review-frame-inspection}

Frame 검토는 정확한 frame identity와 시간 위치에서 composition, visibility, pose, expression, contact, geometry, material, text와 image artifact를 관찰하고 주석을 그 frame에 귀속할 수 있어야 한다.

### 구간 검토 {#review-range-inspection}

구간 검토는 포함 경계와 재생 조건을 명시하고 motion, timing, transition, continuity, collision, event readability와 picture, sound, caption 동기를 시간 흐름 속에서 판정할 수 있어야 한다.

### 전체 작품 검토 {#review-whole-work-inspection}

전체 작품 검토는 scene별 통과를 합산하는 데 그치지 않고 narrative causality, pacing, character arc, setup과 payoff, 장기 continuity, audiovisual balance와 ending state를 작품 순서로 판정할 수 있어야 한다.

### 표본과 전체 Coverage {#review-sampling-full-coverage}

표본 frame이나 선택 구간만 보았다면 그 sampling 범위와 선택 근거를 표시하고 이를 전체 재생 또는 전체 작품 승인과 구분해야 한다.

### 범위 간 결함 전파 {#review-cross-scope-propagation}

한 frame의 결함이 인접 구간의 continuity에 영향을 주거나 한 구간의 변경이 전체 작품 판정을 무효화하면 영향받은 상위와 인접 범위를 다시 검토 대상으로 표시해야 한다.
