# 기준과 비교

## 무엇에 비추어 판정했는지의 명시 {#review-criteria-comparison}

각 검토는 저작 의도, acceptance criterion, 이전 승인본, source, reference 또는 alternative candidate 가운데 무엇을 기준으로 삼았는지 명시해야 한다.

### 관찰 가능한 기준 {#review-observable-criteria}

기준은 판정할 범위, 관찰할 사건이나 상태, 허용 tolerance와 실패 조건을 포함해야 하며 단순한 선호 표현을 필수 조건처럼 제시하지 않아야 한다.

### 기준의 적용 순서 {#review-criteria-precedence}

여러 기준이나 reference가 충돌하면 적용할 기준과 우선순위를 판정 전에 명시하고 과거 승인본이나 reference가 현재 작품의 필수 acceptance criterion을 자동으로 대체하지 않아야 한다.

### 비교 가능한 대상 {#review-comparable-subjects}

두 결과의 차이를 판정할 때는 공통 source와 의도, 대응하는 semantic event 또는 시간 위치, presentation 조건과 허용된 variation을 확인할 수 있어야 한다.

### 정량과 정성의 구분 {#review-quantitative-qualitative-criteria}

정량 threshold의 통과와 정성 판정을 구분하고 수치가 framing, performance, rhythm, readability 또는 작품 의도에 대한 사람의 판단을 대신하지 않아야 한다.

### 직접 관찰 우선 {#review-direct-observation-priority}

최종 판정자는 실제 frame이나 재생 결과를 검토할 수 있어야 하며 summary, thumbnail, metric 또는 다른 사람의 판정만으로 직접 검토를 대신했다면 그 한계를 표시해야 한다.

### 비교 불가능 상태 {#review-noncomparable-state}

대응 시간, source lineage, 필수 reference 또는 presentation 조건이 달라 공정한 비교를 할 수 없으면 차이를 우열이나 회귀로 판정하지 않고 noncomparable 사유를 남겨야 한다.
