# 얼굴 형태와 표정 저작

## 절차적 얼굴 저작 {#actor-facial-authoring}

### 독립적인 얼굴 문서 {#actor-face-document}

사용자는 인물마다 독립된 얼굴 문서를 저장하고 사진이나 fitting 도구 없이 다시 생성할 수 있어야 한다. 문서는 버전, 관측 또는 저작 basis, 중간 형태 제어, 상세 부품 설정, 좌우 비대칭, 외관과 표정을 구별한다. 동일한 최종 문서는 편집 순서와 무관하게 동일한 얼굴을 만든다. 사진에서 추정한 깊이나 가려진 부위는 관측 사실로 표시하지 않는다.

### 이름 있는 해부학적 부품 {#actor-face-anatomical-components}

두개골, 볼과 턱, 눈과 눈꺼풀 및 주름, 코와 비강 입구, 입술과 치열, 귀와 목 연결을 각각 이름 있는 부품과 수식으로 저작할 수 있어야 한다. 세부 제어는 부위, 의미, 단위, 기준값, 허용 범위, 증가와 감소의 효과, 좌우 적용 규칙과 부착 대상을 설명한다. 임의 좌표 변위나 범용 deformation field만으로 해부학적 부품 지원을 주장하지 않는다.

눈썹은 피부 부착과 모발 방향을 유지하면서 저비용 면 표현을 선택할 수 있어야 한다. 머리카락은 두피에 맞춰 저작한 덩어리별 가이드, 폭, 끝의 가늘어짐과 모발 무늬의 밀도로 표현하며 모발 무늬 수와 기하 분할 수를 분리한다. 정적 카드 표현의 조절은 개별 모발 물리 시뮬레이션이나 자동 헤어스타일 복원을 약속하지 않는다.

### 상세 제어와 부위 교체 {#actor-face-controls-replacement}

선택적 단일 값, 배열, 객체와 객체 배열의 생략 기본값과 명시적 교체 의미가 구분되어야 한다. 중간 제어와 상세 override의 해석 순서는 고정하며 최종 범위 위반을 조용히 잘라내지 않는다. 한 부위 교체는 다른 부위의 저작 문서를 보존하고, 맞닿은 피부와 내부 구조가 같은 접합 경계를 사용하게 해야 한다. 좌우는 독립적으로 조절할 수 있어야 한다.

### 정체성과 표정의 분리 {#actor-face-expression}

무표정 형태와 사진에서 관측된 표정, 현재 재생할 표정을 구별해야 한다. 눈꺼풀 움직임은 안구와 각막 크기를 바꾸지 않으며 입술, 턱과 치열은 서로의 접촉과 가림 관계를 유지해야 한다. 표정과 시선은 저장과 재생이 가능해야 하고 지원하지 않는 채널이나 결합은 명시적으로 거부해야 한다. 열린 입의 사진을 단지 모든 제어가 영이라는 이유로 무표정이라고 표시하지 않는다.

### 화면에서 얼굴 편집 {#actor-face-editor}

사용자는 인물과 부위 선택, 수치 및 슬라이더 편집, 회전과 확대, clay 보기, 초기화, 실행 취소와 다시 실행, 프리셋, 문서 저장과 불러오기를 실제 화면에서 사용할 수 있어야 한다.

### 유효한 편집 상태와 복구 {#actor-face-editor-state}

실행 취소와 다시 실행은 성공한 편집만 이동해야 한다. 잘못된 입력이나 실패한 구성은 마지막 유효한 문서와 얼굴을 훼손하지 않아야 한다. 늦게 끝난 이전 구성 요청이 최신 결과를 덮어쓰지 않아야 한다. 초기화도 검증된 편집이며 실행 취소할 수 있어야 한다.

### 휴대 가능한 얼굴 자산 {#actor-face-export}

사용자는 생성된 정적 얼굴을 GLTF 또는 GLB로 내보내고 원본 사진 없이 다시 열 수 있어야 한다. 피부 접합, 치열과 광학 재질이 실제 출력에서 유효해야 하며 지원하지 않는 리소스나 변형은 손실을 숨겨서 내보내지 않는다. 이 기능은 얼굴 자산 내보내기이며 일반 영화 장면 전체의 export 약속은 아니다.

### 대표 사진의 출처 {#actor-face-provenance}

각 얼굴 문서는 선택한 대표 사진의 URL, 알려진 저작자와 라이선스 또는 미확인 상태, digest, 선택 이유와 품질 한계를 보존할 수 있어야 한다. 직접 저작한 basis는 사진을 갖지 않아도 되며 출처는 구성 시 실행되는 입력이 아니다.

### 관측 근거와 닮음 판정 {#actor-face-review}

각 인물의 검토는 부적합한 원본도 inventory에 남기고 대체 후보의 URL, 저작자, 라이선스, digest와 검토 결정을 기록한다. 구성 성공, 독립 재생, GLTF 유효성, 정면과 양쪽 사선 및 측면, 후면, 기준 자세와 clay 캡처의 완전성, 직접 열람, 닮음과 잔여 결함은 별도로 판단한다. 수치 검증이나 캡처 성공만으로 닮음을 수락하지 않는다. 모발 카드를 사용한 경우 두피 부착, 가르마, 덩어리 연결과 실루엣도 실제 렌더에서 검토한다.
