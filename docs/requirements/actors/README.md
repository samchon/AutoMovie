# Actor 요구사항

Actor는 story character, performer identity, model, rig, voice와 시간에 따른 performance를 연결한다. 일반 전신 저작의 ceiling은 실제 관절과 접지를 지키는 의미 풍부한 proxy이다. [얼굴 저작](facial-authoring/README.md)은 이름 있는 부품과 수식에 의한 상세 형상을 별도로 허용하지만, 사진과 동일한 외모나 완성된 인간 catalogue를 보장하지 않는다.
