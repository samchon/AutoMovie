# Actor 요구사항

Actor는 story character, performer identity, model, rig, voice와 시간에 따른 performance를 연결한다. AutoMovie의 직접 저작 ceiling은 실제 관절과 접지를 지키는 의미 풍부한 proxy이며 특정인의 사실적 외모를 복원하거나 완성된 인간 catalogue를 제공하지 않는다.
