# 범위와 건물 Identity

## 건물 동 단위의 외관 책임 {#building-exterior-scope}

건물 외관은 하나 이상의 건물 동의 전체 외형, 외피, 외부 개구부, 건물에 직접 결합된 외부 공간과 시설을 독립적으로 저작·검증·렌더할 수 있어야 한다.

### 건물 Identity {#building-exterior-identity}

각 건물 동, mass, storey, facade region, roof, opening, exterior space와 attachment는 map, interior, camera와 evidence가 공유할 안정된 identity를 가져야 한다.

### Exterior-only 건물 {#building-exterior-only}

Interior가 필요하지 않은 배경 건물, 원경 skyline, facade set와 거리 세트는 exterior-only scope로 명시할 수 있어야 하며 존재하지 않는 내부를 추정하거나 검증했다고 주장하지 않는다.

### Interior와 연결된 건물 {#building-exterior-linked-interior}

Interior와 같은 building identity를 공유하는 경우 footprint, level, envelope, opening와 current state가 양쪽에서 일치해야 한다.

### 외부 세계 경계 {#building-exterior-map-boundary}

공원, 하천, 도로와 광역 지형은 [맵 요구사항](../map/README.md)이 소유하고, 건물 외관은 대지 접점과 건물에 직접 결합된 외부 요소를 소유한다.
