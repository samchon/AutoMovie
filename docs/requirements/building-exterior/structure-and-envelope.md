# 구조와 외피

## 건물의 지지와 환경 경계 {#building-structure-envelope}

Foundation, column, beam, wall, slab, core, brace와 roof structure를 non-structural facade, insulation, waterproofing, cavity, cladding와 interior finish에서 구분하면서 실제 위치와 두께를 가진 construction으로 연결할 수 있어야 한다.

### 지지 관계 {#building-structural-support}

Mass, slab, roof, facade, balcony, equipment와 attachment가 foundation, structure, subframe 또는 declared set support 중 무엇에 지지되는지 표현하고 떠 있거나 연결이 끊긴 주요 요소를 찾을 수 있어야 한다. 시각적 support 검토와 전문 구조 성능 분석은 구분해야 한다.

### Envelope Layer {#building-envelope-layers}

Structure, substrate, air·vapor layer, insulation, waterproofing, subframe, exterior finish, cavity와 interior finish가 exterior-to-interior 순서, thickness, side, termination와 region을 가질 수 있어야 한다. Exterior-only set는 저작하지 않은 hidden layer를 complete assembly로 추정하지 않아야 한다.

### 양면과 단부 {#building-envelope-faces-edges}

Exterior face, interior face, edge, end, reveal, soffit와 cut face를 구분하여 서로 다른 material·finish·detail을 적용하면서 같은 construction identity와 total thickness를 유지해야 한다.

### 외피 연속성 {#building-envelope-continuity}

Opening, drain, service penetration과 intended open set edge를 제외한 enclosure gap, inverted face, overlapping layer, impossible wrap와 contradictory side ownership을 탐지할 수 있어야 한다. Exterior-only set의 의도된 open edge는 카메라 유효 범위와 함께 명시되어야 한다.

### Interior와의 구조 정합 {#building-structure-interior-coordination}

Interior가 연결되면 column, beam, slab, core, shaft, structural wall와 roof support의 identity, section, position, extent와 penetration이 양쪽에서 같아야 한다. Interior가 필요한 opening·shaft·clearance와 exterior가 필요한 support·envelope가 충돌하면 한쪽 geometry를 숨기지 말고 coordination failure를 보고해야 한다.
