# 구조와 외피

## 건물의 지지와 환경 경계 {#building-structure-envelope}

Foundation, column, beam, wall, slab, brace와 roof structure를 non-structural facade, insulation, waterproofing, cavity, cladding와 interior finish에서 구분하면서 하나의 두께 있는 assembly로 연결할 수 있어야 한다.

### 지지 관계 {#building-structural-support}

Mass, slab, roof, facade와 attachment가 무엇에 지지되는지 표현하고 떠 있거나 연결이 끊긴 주요 요소를 찾을 수 있어야 한다.

### Envelope Layer {#building-envelope-layers}

Structure, substrate, air·vapor layer, insulation, waterproofing, subframe, exterior finish, cavity와 interior finish가 순서, thickness와 region을 가질 수 있어야 한다.

### 양면과 단부 {#building-envelope-faces-edges}

Exterior face, interior face, edge, end, reveal와 cut face를 구분하여 서로 다른 material·finish·detail을 적용하면서 같은 construction identity를 유지해야 한다.

### 외피 연속성 {#building-envelope-continuity}

Opening과 intended interface를 제외한 enclosure gap, inverted face, overlapping layer와 contradictory side ownership을 탐지할 수 있어야 한다.
