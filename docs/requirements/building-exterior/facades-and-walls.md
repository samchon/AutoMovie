# 입면과 외벽

## 건물 외형을 구성하는 입면 {#building-facades-walls}

Facade는 level strip의 단순 반복에 한정하지 않고 bay, column, beam, wall, curtain wall, screen, louver, balcony, oriel, arcade, arch, buttress, deep reveal와 자유 조형을 실제 scale의 solid·surface·assembly로 조합할 수 있어야 한다.

### 배치 기준 {#building-facade-placement-basis}

입면 요소는 grid, datum, storey, bay, mass surface, surface coordinate, path 또는 자유 배치에 따라 구성하고 proportion, symmetry, asymmetry, rhythm, gradient와 unique exception을 표현할 수 있어야 한다.

### 깊이와 Relief {#building-facade-depth}

Projection, recess, frame, pilaster, reveal, cornice, screen와 cavity가 실제 depth와 shadow를 가져야 하며 평면 texture만으로 모든 입면 형상을 대신하지 않는다.

### Corner와 Transition {#building-facade-corners}

서로 다른 입면, mass, material, pattern와 representation이 만나는 corner, return, setback와 curved transition의 형상, thickness, module termination와 마감 연속성을 제어할 수 있어야 한다.

### Interior 경계 관계 {#building-facade-interior-boundary}

Interior와 연결된 건물에서는 외벽 위치, inside·outside orientation, construction thickness, column·slab edge와 opening reveal이 내부 room boundary, usable area, floor·ceiling junction와 같은 shared identity를 사용해야 한다. Interior lining이나 room boundary 변경도 exterior wall thickness와 facade attachment clearance를 다시 검토하게 해야 한다.

### Facade Set 완결성 {#building-facade-set-completeness}

독립 facade set는 유효한 view 방향과 거리, side return, top·bottom edge, backside treatment, support, opening 뒤의 visible depth와 set extension 경계를 선언해야 한다. 선언 밖의 뒷면, room, 구조와 인접 facade를 존재하는 것으로 간주하지 않아야 한다.
