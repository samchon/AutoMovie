# 건물 외관 요구사항

## 독립된 건물 외관 계약 {#building-exterior-contract}

건물 외관은 건물 동의 전체 매스, 대지와의 접점, 면적·높이·층별 기준, 구조와 외피, 입면, 지붕, 개구부, 외부 공간, 설비 interface와 부착 시설을 소유한다. Interior가 없는 배경 건물, 원경 mass, exterior stage와 facade set도 선언된 camera·거리·공간 범위 안에서 완전한 외관 대상으로 저작·검증·렌더할 수 있다.

Interior가 연결되면 어느 한쪽을 다른 쪽의 참고 사본으로 두지 않는다. Building, boundary, level, opening, structure, service port와 coordinate identity를 공유하고 massing, area, storey height, envelope, opening, structure, service와 transform 변경을 양방향으로 조정하거나 모순으로 거부해야 한다.

이 주제는 건물과 건물에 직접 결합된 외부 요소만 다룬다. 선박, 열차, 항공기, 우주선과 다른 운송체의 exterior는 이 계약의 지원 범위가 아니다.
