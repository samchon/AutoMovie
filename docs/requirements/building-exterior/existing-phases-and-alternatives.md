# 기존 상태, 공사 단계와 대안

## 같은 건물의 여러 설계 상태 {#building-exterior-existing-phases}

Existing, retained, demolished, temporary, relocated, repaired와 new building, exterior element, material, service와 attachment를 구분하고 survey state, construction phase, renovation와 selected design을 같은 stable identity 아래 비교할 수 있어야 한다.

### Survey와 불확실성 {#building-exterior-survey-uncertainty}

Measured, referenced, inferred, fictional와 inaccessible exterior condition을 구분하고 coordinate, dimension, material, damage, hidden assembly와 interior relation의 source와 uncertainty를 기록해야 한다. Exterior-only 자산의 보이지 않는 backside와 내부를 surveyed fact로 채우지 않아야 한다.

### 공사 단계 {#building-exterior-construction-phases}

Demolition, excavation, temporary works, structure, envelope, facade, roof, service, finishing와 occupation 단계에 따라 visible, supported, enclosed, accessible, collidable, measurable와 weather-tight state가 어떻게 달라지는지 표현할 수 있어야 한다. Phase는 필요할 때 prerequisite graph를 가질 수 있으며 선형 순서를 강제하지 않아야 한다.

### 설계 대안 {#building-exterior-alternatives}

Massing, site placement, level, structure, facade, opening, roof, material, service, representation와 attachment 대안을 공통 base와 차이로 비교하고 선택 전까지 별도 identity와 provenance를 유지해야 한다. 한 대안의 interior, map, drawing와 render를 다른 대안에 섞지 않아야 한다.

### 변경 영향 {#building-exterior-change-impact}

Coordinate, area, height, structure, envelope, opening, material, pattern와 service 변경이 linked interior, map seam, quantity, shadow, view, render와 evidence에 미치는 영향을 식별하고 dependent artifact를 stale로 만들어야 한다.

### 정본 State {#building-exterior-canonical-state}

각 shot, drawing, schedule, quantity, analysis와 capture는 어느 survey, revision, phase, alternative, representation와 film-time state를 사용했는지 명시해야 한다. Pending, present, removed, hidden와 intentionally absent를 구분해야 한다.

### Interior와 Map Phase 정합 {#building-exterior-phase-coordination}

Linked interior와 map connection은 같은 phase·alternative identity 또는 명시적 state mapping을 가져야 한다. 철거된 wall의 interior finish, 설치 전 opening을 통과하는 route, 연결 전 utility를 사용하는 equipment와 서로 다른 phase의 terrain contact를 current 상태로 조합하지 않아야 한다.
