# 기존 상태, 공사 단계와 대안

## 같은 건물의 여러 설계 상태 {#building-exterior-existing-phases}

Existing, retained, demolished, temporary와 new exterior element를 구분하고 survey state, construction phase, renovation와 selected design을 같은 building identity 아래 비교할 수 있어야 한다.

### 공사 단계 {#building-exterior-construction-phases}

Demolition, structure, envelope, facade, roof, service와 finishing 단계에 따라 visible geometry, support, protection와 access가 어떻게 달라지는지 표현할 수 있어야 한다.

### 설계 대안 {#building-exterior-alternatives}

Massing, level, facade, opening, roof, material와 attachment 대안을 공통 base와 차이로 비교하고 선택 전까지 별도 provenance를 유지해야 한다.

### 변경 영향 {#building-exterior-change-impact}

Area, height, opening, material와 pattern 변경이 interior constraint, quantity, shadow, view, render와 evidence에 미치는 영향을 식별할 수 있어야 한다.

### 정본 State {#building-exterior-canonical-state}

각 shot, drawing와 quantity는 어느 survey, phase와 alternative를 사용했는지 명시해야 한다.
