# 외장 Pattern과 반복 요소

## 실제 Module을 가진 외장 Pattern {#building-exterior-patterns-instances}

Brick, stone, tile, siding, panel, louver, roof unit, railing member와 facade bay를 actual module, surface coordinate, joint, fixing와 boundary rule로 배치할 수 있어야 한다.

### Surface 연속성 {#building-exterior-pattern-continuity}

Pattern은 plane, curve, slope, corner와 mass transition을 따라가며 opening, edge, roof line와 adjacent facade에서 continuity 또는 intentional break를 선언할 수 있어야 한다.

### 절단과 제작 단위 {#building-exterior-pattern-cuts}

Module size, maximum fabrication extent, cut, bend, minimum piece, border와 corner unit를 검토하고 quantity와 waste를 산출할 수 있어야 한다.

### 반복 Instance와 예외 {#building-exterior-instance-exceptions}

각 instance는 identity, transform, material variation, seed와 corner·opening adjacent·damaged exception을 유지해야 한다.

### 결정론적 변주 {#building-exterior-pattern-variation}

Handmade irregularity, settlement, discoloration와 damage는 bounded rule과 seed로 재현되어야 하며 관련 없는 변경으로 다시 섞이지 않아야 한다.
