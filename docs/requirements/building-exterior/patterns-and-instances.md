# 외장 Pattern과 반복 요소

## 실제 Module을 가진 외장 Pattern {#building-exterior-patterns-instances}

Brick, stone, tile, siding, panel, louver, roof unit, railing member, facade bay와 repeated storey·mass component를 prototype, actual module, surface coordinate, joint, fixing와 boundary rule로 배치할 수 있어야 한다.

### Surface 연속성 {#building-exterior-pattern-continuity}

Pattern은 plane, curve, slope, corner와 mass transition을 따라가며 opening, edge, roof line, movement joint와 adjacent facade에서 continuity, wrap, termination 또는 intentional break를 선언할 수 있어야 한다.

### 절단과 제작 단위 {#building-exterior-pattern-cuts}

Module size, maximum fabrication extent, cut, bend, minimum piece, border, opening return와 corner unit를 실제 host extent에서 검토하고 resolved quantity, fixing과 waste를 산출할 수 있어야 한다.

### 반복 Instance와 예외 {#building-exterior-instance-exceptions}

각 prototype과 instance는 identity, full transform, host·group membership, material, visibility, phase, state, seed와 corner·opening-adjacent·damaged·story-relevant exception을 유지해야 한다. Nested group과 imported prototype도 같은 규칙을 따라야 한다.

### 결정론적 변주 {#building-exterior-pattern-variation}

Handmade irregularity, settlement, discoloration와 damage는 bounded rule, spatial correlation와 stable seed로 재현되어야 하며 관련 없는 변경으로 다시 섞이지 않아야 한다. 변주가 opening, support, joint, waterproofing, minimum piece와 required clearance를 깨뜨리지 않아야 한다.

### 반복 Building과 Storey {#building-exterior-repeated-building-storey}

반복 building unit, wing, storey, facade bay와 balcony stack은 compact rule로 생성할 수 있으나 각 resolved member의 building·storey·opening identity, site placement, height, state와 explicit override를 보존해야 한다. Background population 안의 landmark와 story-relevant building을 익명 prototype으로 축약하지 않아야 한다.

### Bounded Expansion과 Identity {#building-exterior-instance-bounded-expansion}

Expanded building, element, module, triangle, material, collider와 light count의 최대값을 선언하고 instancing, batching, culling와 LOD 뒤에도 selection, diagnostic, collision, quantity, phase와 evidence에 필요한 member identity를 유지해야 한다. Budget 초과는 silent omission이 아니라 분할, proxy, 지연 또는 refusal 중 적용된 결과를 보고해야 한다.
