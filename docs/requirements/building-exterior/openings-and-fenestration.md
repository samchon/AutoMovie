# 개구부와 창호

## 외피를 실제로 관통하는 Opening {#building-openings-fenestration}

Window, door, gate, skylight, vent, service penetration과 다른 opening은 host wall·roof의 실제 layer depth를 절단하고 exterior와 linked interior, exterior void 또는 declared set backing 중 무엇을 연결하는지 식별해야 한다.

### 창호 구성 {#building-fenestration-components}

Frame, sash, leaf, mullion, transom, sill, head, jamb, glass, opaque panel, spandrel, seal, flashing, drainage와 hardware를 declared representation과 검토 목적에 필요한 상세 수준에서 구성할 수 있어야 한다.

### 자유 형상과 배열 {#building-opening-form-layout}

Rectangular, circular, arched, sloped와 freeform opening을 grid, bay, host-surface coordinate 또는 custom rule로 배치하고 반복 prototype과 unique exception의 identity를 함께 표현할 수 있어야 한다.

### 가동과 차양 State {#building-opening-operable-state}

Open, closed, locked, rotated, sliding, folded와 removed state, shutter, blind, awning, louver와 screen이 sweep·clearance, access, light, view, sound, weather와 drainage boundary에 함께 반영되어야 한다.

### 내외부 일관성 {#building-opening-interior-consistency}

Interior가 연결된 경우 양쪽은 같은 opening cut identity, host, position, orientation, clear aperture, frame depth와 operable state를 사용해야 하며 exterior flashing·sill·drainage와 interior trim은 독립적으로 상세화할 수 있어야 한다. 어느 쪽에서 opening을 이동, resize, close 또는 remove해도 상대편 route, view, light, service와 finish를 다시 검토해야 한다.

### Exterior-only Opening {#building-opening-exterior-only}

Exterior-only building이나 facade set의 opening은 opaque backing, bounded visible recess, exterior-to-exterior passage 또는 intentionally open void 중 어느 표현인지 선언해야 한다. 검은 plane이나 투명 surface가 보인다는 이유로 room, glazing assembly나 interior circulation이 존재한다고 주장하지 않아야 한다.
