# 외관 산출물

## 동일한 건물에서 나온 외관 자료 {#building-exterior-deliverables}

Site placement, mass axonometric, directional elevation, facade unfolding, roof plan, exterior section, opening detail, material·panel layout, schedule, quantity, render와 guide pass는 같은 building identity와 state를 사용해야 한다.

### 치수와 Annotation {#building-exterior-dimensions-annotations}

Footprint, overall dimension, level, height, radius, angle, setback와 element spacing을 source identity에 연결하여 표시할 수 있어야 한다.

### 표와 수량 {#building-exterior-schedules-quantities}

Building, facade region, opening, material, panel, roof와 attachment의 count, area, length, volume와 waste를 unit, scope와 exclusions와 함께 제공해야 한다.

### Exterior-only Evidence {#building-exterior-only-evidence}

Exterior-only set는 interior가 없음을 명시하면서 외관 geometry, placement, camera visibility와 render 범위에 대한 완전한 evidence를 제공할 수 있어야 한다.

### Capture Provenance {#building-exterior-capture-provenance}

Render와 capture는 source revision, building, camera, time, map context, weather와 current state를 기록해야 한다.
