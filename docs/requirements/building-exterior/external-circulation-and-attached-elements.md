# 외부 Circulation과 부착 시설

## 건물과 결합된 외부 요소 {#building-external-circulation-attachments}

Exterior stair, fire escape, ramp, ladder, bridge, canopy, awning, louver, shutter, maintenance platform, sign와 building-mounted equipment를 명시적 support와 connection으로 표현할 수 있어야 한다.

### Circulation 연결 {#building-external-circulation}

Stair, ramp, bridge와 walkway는 시작·끝 level, landing, width, slope, guard와 door 또는 map path connection을 가져야 한다.

### 부착과 지지 {#building-external-attachment-support}

Attachment는 host wall, roof, structure 또는 foundation의 anchor, orientation, support와 clearance를 가져야 한다.

### 가동 요소 {#building-external-operable-element}

Awning, shutter, gate, folding stair와 maintenance equipment의 state와 movement volume이 facade, opening, map와 actor를 간섭하는지 확인할 수 있어야 한다.

### 무지지 요소의 거부 {#building-external-attachment-refusal}

Anchor 없는 attachment, 끊긴 path, level mismatch와 impossible clearance를 named finding으로 남겨야 한다.
