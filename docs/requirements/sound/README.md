# 음향 요구사항

음향은 dialogue, foley, effect, ambience, music와 silence를 story event, world source, fixed film clock와 deterministic mix에 연결한다. Visual scene와 별도 장식 track가 아니라 같은 사건과 공간 state를 듣게 하는 production layer이며, 반복 seek와 최종 media probe로 timing과 delivery를 증명한다. 사용자는 어떤 recording, library, synthesis 또는 generation provider의 bytes를 채택할지 선택하고 AutoMovie는 특정 공급자를 필수값으로 정하지 않는다.
