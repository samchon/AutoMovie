# 장면 연출 요구사항

장면 연출은 story event를 실제 공간의 actor, object, mark, interaction, camera access와 film-time 변화로 배치한다. 감정 adjective를 자동 동작으로 바꾸는 단계가 아니라 관찰 가능한 blocking과 timing을 저작하는 단계다.

각 staging plan은 [촬영 가능한 scene](../story/scenes-and-observable-action.md#story-scenes-observable-action), [production design의 location과 state](../production-design/locations-and-world-context.md#production-design-locations-context), 배치에 사용한 map·exterior·interior와 [asset geometry](../asset-authoring/geometry.md#asset-general-geometry)의 identity와 revision을 추적한다. Camera, lighting, motion와 sound는 같은 plan과 film clock을 읽으며, 어느 하류 선택도 상위 story fact나 resolved scene geometry를 조용히 바꾸지 않는다.
