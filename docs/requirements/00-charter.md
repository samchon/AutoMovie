# Product charter

## Prototype delivery {#prototype-delivery}

Automovie delivers a deterministic blocking pass whose staging, motion, timing, sound plan, and review evidence can be reproduced. The delivery is a controllable prototype and a hint-motion artifact for a later repaint lane, not a finished photoreal shot.

## Authorability threshold {#authorability-threshold}

A capability belongs in automovie only when a coding agent can author its controlling facts through typed source or declared production records and the deterministic pipeline can validate and render the result. A hidden heuristic that the author cannot drive does not raise the product ceiling.

## Decided exclusions {#decided-exclusions}

Automovie does not reconstruct arbitrary people, generate a catalogue of content, solve production-grade cloth or destruction, or become an interactive editor. An exclusion reopens only when a deterministic representation, an authoring path, bounded validation, and a proving render path exist together.
