# Alternative와 의도적 위반

## 비교 가능하고 추적 가능한 Lighting Choice {#lighting-alternatives-intentional-deviations}

Base, alternate take, relight, time-of-day variant와 intentional deviation은 stable identity, common story·design·geometry source, 달라지는 lighting state, applicable shot interval와 acceptance를 가져야 한다.

### 의도적 위반 {#lighting-intentional-deviations}

Continuity break, unmotivated-looking source, stylized shadow, selective reflection, practical mismatch와 exposure contrast를 의도적으로 유지할 때는 affected rule, story reason, camera·subject·interval, 관객이 읽어야 할 cue와 허용 consequence를 선언해야 한다.

### A/B 조건 {#lighting-alternative-comparison-conditions}

Lighting alternative의 A/B는 camera, staging, resolved geometry, material, time sample, exposure, display view와 raster를 고정하거나 차이로 밝혀 어느 lighting choice가 결과를 바꿨는지 관찰할 수 있어야 한다.

### Branch State {#lighting-alternative-state-branches}

각 alternative는 inherited environment, source, filter·link, practical control, shadow·reflection와 color state의 독립 lineage를 가지며 선택 전 서로 다른 branch의 state와 review evidence를 조합하지 않아야 한다.

### Selection Receipt {#lighting-alternative-selection}

선택 결과는 chosen branch, 이유, 충족한 acceptance, 남은 approximation, continuity와 budget consequence, 대체된 branch를 기록하고 edit와 render가 같은 선택을 읽어야 한다.

### Alternative Refusal {#lighting-alternative-refusal}

Common condition이 불명확한 비교, reason 없는 rule suppression, branch state 혼합, unsupported optical claim과 선택되지 않은 source의 잔류를 named finding으로 남겨야 한다.
