# 저작 계약 판별자

## Host와 population 의미 {#agent-production-evidence-authoring-contracts}

### Contract discriminator routing {#agent-production-evidence-contract-discriminators}

공통 저작 계약은 한 단위의 literal body가 답할 수 있는 principle, 완성 population 비교가 필요한 obligation, upstream relation, work-specific discovery와 source owner를 서로 다른 host와 cardinality로 선택해야 한다. Unit claim을 population account로, 한 관계를 전체 file로, 미실현 단원을 exclusion으로 바꾸어 graph를 통과시켜서는 안 된다.

서사 population의 기여, 연결, continuity, 시간, speech, voice와 pacing, screenplay의 parse form, semantic completion, production direction과 locked revision, design의 style, scale, layer completion과 prop ownership은 서로 대신하지 않는 stable target identity를 가져야 한다. 선택한 제작 종류와 stage에서 활성인 target만 정확한 host population에 투영하고 inactive structured rule은 claim이 될 수 없다.
