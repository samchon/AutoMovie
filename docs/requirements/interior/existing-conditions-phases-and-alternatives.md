# 기존 상태, 단계와 대안

## 같은 Interior의 여러 State {#interior-existing-phases-alternatives}

Existing, retained, demolished, temporary, relocated, repaired와 new space, element, finish, furniture와 service를 같은 identity 아래 phase와 alternative로 비교할 수 있어야 한다.

### Survey와 불확실성 {#interior-existing-survey-uncertainty}

Measured, referenced, inferred, fictional와 inaccessible condition을 구분하고 dimension, material, damage와 hidden assembly의 uncertainty를 기록해야 한다.

Observation, drawing-derived measurement, automated interpretation, user-confirmed fact와 design decision을 구분하고 source location, observed time, confidence와 transformation을 추적할 수 있어야 한다. 보이지 않는 wall thickness, service, adjacent room와 외피 condition을 기존 사실로 확정하지 않아야 한다.

### Construction과 Renovation Phase {#interior-construction-renovation-phases}

Demolition, structure, partition, service rough-in, ceiling, finish, installation, dressing와 occupation 단계마다 visible, supported, accessible, collidable와 usable state를 표현할 수 있어야 한다.

### Design Alternative {#interior-design-alternatives}

Plan, room use, ceiling, material, pattern, furniture, lighting와 service 대안을 공통 base와 차이로 보존하고 선택 전 결과를 다른 대안의 정본에 섞지 않아야 한다.

Alternative는 전체 interior 복사본이 아니라 추가, 교체, 비활성, 삭제와 override의 주소 가능한 차이로 보존할 수 있어야 한다. 여러 선택 축의 조합 가능성, 우선순위와 충돌을 명시하고 base 변경 뒤 사라진 대상에 대한 override를 자동 병합하지 않아야 한다.

### 변경 영향 {#interior-change-impact}

Boundary, level, opening, finish, object와 service 변경이 exterior consistency, area, clearance, route, quantity, camera, sound와 evidence에 미치는 영향을 식별할 수 있어야 한다.

### Canonical State {#interior-canonical-state}

각 shot, drawing, quantity와 review는 어느 survey, phase, alternative와 film-time state를 사용했는지 명시해야 한다.

Design phase, construction phase, operating state, season·daylight state, continuous simulation time와 film clock을 서로 다른 축으로 유지해야 한다. 한 축의 현재 선택이 다른 축을 묵시적으로 덮어쓰지 않고 같은 선택과 시간 표본을 다시 해석하면 같은 resolved interior가 나와야 한다.
