# 색, Style, Form과 Art

## 작품이 소유하는 Interior 표현 {#interior-color-style-form-art}

Palette, contrast, saturation, material character, proportion, rhythm, ornament, graphic, artwork와 sculptural form을 project art direction과 공간 identity에 연결할 수 있어야 한다.

### Style은 Preset이 아님 {#interior-style-not-preset}

시대와 양식을 닫힌 preset 목록으로 고르도록 제한하지 않고 형상, 재료, pattern, color, wear와 object composition의 명시적 선택으로 구성해야 한다.

Ornament와 freeform은 moulding catalogue의 존재가 아니라 profile, sweep, loft, relief, cut, boolean, repetition, symmetry, external asset와 이들의 composition을 사용자가 선택할 수 있는 저작 자유로 성립해야 한다. Style 이름만으로 역사적 정확성, 재료나 제작 방식을 자동 확정하지 않아야 한다.

### 공간별 차이와 연속성 {#interior-style-space-continuity}

Building, storey, unit, room와 zone마다 같은 style family를 공유하거나 다르게 만들 수 있고, threshold에서 continuity 또는 intentional contrast를 선언할 수 있어야 한다.

### Art와 Signage {#interior-art-signage}

Painting, sculpture, mural, graphic, sign, label와 display는 source, license, actual size, placement, visibility와 story role을 가져야 한다.

### Reference와 결과의 구분 {#interior-style-reference-boundary}

Mood board, reference image와 verbal style은 설계 입력이며 최종 geometry와 material의 존재 증거가 아니다. 실제 source와 render에서 구현 여부를 별도로 확인해야 한다.

### 색 관리와 비교 조건 {#interior-color-management-comparison}

Material base color, texture pixel, light color, scene-referred result와 display 또는 print color를 구분하고 color space, encoding, alpha 의미, display transform과 gamut 처리를 기록할 수 있어야 한다. 대안 비교는 조명, camera exposure와 표시 조건을 고정하거나 차이를 명시하여 화면 변환의 차이를 재료 변경으로 오인하지 않아야 한다.
