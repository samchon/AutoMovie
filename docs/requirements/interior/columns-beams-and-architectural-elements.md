# 기둥, 보와 건축 요소

## 실내에서 드러나는 건축 요소 {#interior-architectural-elements}

Column, beam, brace, arch, vault, pilaster, niche, fireplace, platform, stage, built-in stair와 project-defined architectural feature를 실제 형상, support와 공간 관계로 표현할 수 있어야 한다.

### 구조와 장식의 구분 {#interior-structural-decorative-distinction}

Load-bearing element, enclosure, finish build-up와 decorative imitation을 구분하고 검증하지 않은 장식 요소를 구조적 지지로 사용하지 않아야 한다.

### Host와 관통 {#interior-element-host-penetration}

Beam, column, stair와 shaft가 floor, ceiling, wall과 만날 때 opening, wrap, trim, fireproofing와 clearance를 같은 resolved geometry에서 확인할 수 있어야 한다.

### 자유 형상과 시대 {#interior-element-open-form}

고전 order, 산업 구조, 토속 construction, 현대 freeform과 fictional form을 열린 geometry 능력으로 구성하고 특정 시대 catalogue에 제한하지 않아야 한다.

### Support Gap {#interior-element-support-gap}

떠 있는 beam, 끊긴 stair, host 없는 built-in, 충돌하는 structural element와 설명되지 않은 penetration을 named finding으로 남겨야 한다.
