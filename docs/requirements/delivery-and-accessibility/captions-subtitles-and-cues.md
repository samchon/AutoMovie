# Caption, Subtitle와 Cue

## 시간과 화면 영역을 가진 Text Alternative {#delivery-captions-subtitles-cues}

Caption와 subtitle cue는 stable identity, language, start·end, text, speaker 또는 sound role, region, line·position, style-like semantic와 source utterance 또는 event relation을 가져야 한다.

### Caption와 Subtitle {#delivery-caption-subtitle-distinction}

Dialogue translation, same-language caption, sound description, song lyric excerpt, chapter와 metadata cue를 구분하고 하나의 text track로 의미를 잃지 않아야 한다.

### Reading과 Overlap {#delivery-caption-reading-overlap}

Cue duration, line length, overlap, shot cut, speaker change와 on-screen text collision을 delivery profile과 language에 따라 검토할 수 있어야 한다.

### Styling과 Safe Region {#delivery-caption-style-region}

Text color, background, alignment, vertical writing-like supported mode, safe region와 user override 가능성을 표현하고 beauty composition 위에 고정 위치를 강제하지 않아야 한다.

### Cue Refusal {#delivery-caption-refusal}

Reversed time, film 밖 cue, missing language, unreadable overlap, empty required text와 source dialogue mismatch를 거부해야 한다.
