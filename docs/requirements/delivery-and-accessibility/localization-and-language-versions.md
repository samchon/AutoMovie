# Localization과 언어 Version

## 언어별로 추적되는 Film 자산 {#delivery-localization-language-versions}

Dialogue, subtitle, caption, audio description, title, on-screen text, metadata와 voice를 language, locale-like profile, source text, translation와 revision으로 연결할 수 있어야 한다.

### Original과 Translation {#delivery-original-translation}

원문 identity, translator 또는 provider, translation, pronunciation, cultural adaptation와 approval를 구분하고 translated text를 원본에 덮어쓰지 않아야 한다.

### Dub와 Timing {#delivery-dub-timing}

Dub voice, utterance duration, actor identity, performance timing, viseme와 mix를 language version마다 연결하고 source language timing을 그대로 가정하지 않아야 한다.

### Text Expansion과 Layout {#delivery-text-expansion-layout}

Caption, title와 on-screen text의 길이, 줄바꿈, writing direction, font coverage와 safe region을 실제 target language에서 검토해야 한다.

### Localization Refusal {#delivery-localization-refusal}

Missing translation, mixed locale, unsupported glyph, stale cue timing, wrong voice와 untranslated required text를 거부해야 한다.
