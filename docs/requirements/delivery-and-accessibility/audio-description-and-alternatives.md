# Audio Description과 대체 Media

## Visual Information의 시간 기반 대체 {#delivery-audio-description-alternatives}

Audio description은 visual event, character, action, setting와 on-screen text 중 전달할 정보를 narration cue, language, voice, available gap와 mix relation으로 표현할 수 있어야 한다.

### Gap와 Priority {#delivery-description-gaps-priority}

Dialogue, critical sound, music와 available silence를 고려하여 description timing과 priority를 저작하고 원 dialogue를 무조건 덮지 않아야 한다.

### Extended와 Standard {#delivery-description-modes}

기존 film timing 안의 standard description, pause 또는 alternate timeline을 쓰는 extended description와 text transcript를 구분할 수 있어야 한다.

### Other Alternatives {#delivery-other-alternatives}

Descriptive transcript, sign-language rendition, clean audio와 user-selectable alternative를 delivery profile에 포함할 수 있으나 구현하지 않은 항목은 unsupported 또는 absent로 명시해야 한다.

### Description Refusal {#delivery-description-refusal}

Missing visual target, overlapping required dialogue, wrong language, stale edit timing와 source film보다 긴 unhandled cue를 거부해야 한다.
