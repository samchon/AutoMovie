# 구조 비교와 Review

## Repaint가 보존해야 하는 Film 구조 {#repaint-structural-comparison-review}

Source와 rendition의 subject count, identity, mask, pose landmarks, silhouette, camera composition, contact, screen direction와 critical event content를 비교할 수 있어야 한다.

### Pixel와 Structure {#repaint-pixel-structure-distinction}

Pixel likeness와 structural equivalence를 구분하고 style change가 크더라도 required geometry relation은 preserved tolerance 안에 있어야 한다.

### Negative Failure {#repaint-structural-failures}

추가·삭제된 subject, changed costume identity, broken limb, moved camera, lost contact, unreadable event와 altered text를 각각 named finding으로 남겨야 한다.

### Rendition Review {#repaint-rendition-review}

Current output을 직접 보고 material, identity, artifact, temporal consistency와 source preservation을 평가하며 provider 설명과 thumbnail만으로 판단하지 않아야 한다.

### Review Status {#repaint-review-status}

Generated, compared, reviewed, accepted, rejected, failed, unsupported와 not-run을 구분하고 structural metric pass만으로 visual acceptance를 주장하지 않아야 한다.
