# Eligibility와 선행 Gate

## Current Deterministic Source 이후의 Repaint {#repaint-eligibility-prerequisites}

Repaint는 compiled source, current deterministic frame, required structural pass, shot acceptance와 source review가 같은 fingerprint에서 성공한 뒤에만 실행할 수 있어야 한다.

### Source Failure 우선 교정 {#repaint-source-failure-first}

Subject 누락, wrong pose, contact, camera, event, timing, screen direction와 continuity defect는 source에서 고치고 다시 capture해야 하며 prompt로 덮지 않아야 한다.

### Delivery Declaration {#repaint-delivery-declaration}

Production과 shot은 repaint 사용 여부, required source time, output purpose와 sequence policy를 명시해야 한다.

### Current Evidence {#repaint-current-evidence}

Source 수정 뒤 previous frame, review와 repaint receipt는 stale이며 같은 path의 old pixels를 input으로 사용하지 않아야 한다.

### Eligibility Refusal {#repaint-eligibility-refusal}

Missing current frame, failed acceptance, absent reference, deterministic-only policy와 stale fingerprint를 거부해야 한다.
