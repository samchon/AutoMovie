# Art Direction과 시각 언어

## 반복 적용 가능한 시각 원칙 {#production-design-art-direction}

Shape language, proportion, palette, material character, contrast, density, aging, graphic language와 composition tendency를 여러 subject와 location에 적용 가능한 project-owned 원칙으로 정의할 수 있어야 한다.

### Reasoned Choice {#production-design-reasoned-choice}

각 핵심 원칙은 story, character, era, environment 또는 production constraint 중 무엇에 답하는지 설명하고 장식적 adjective 목록으로 끝나지 않아야 한다.

### 일관성과 차이 {#production-design-consistency-variation}

같은 세계의 shared language와 faction, character, place, time phase별 intentional difference를 함께 표현할 수 있어야 한다.

### Reference에서 저작으로 {#production-design-reference-realization}

Reference의 구체적 관찰을 geometry, material, pattern, light, dressing와 state 선택으로 변환하고 reference likeness 자체를 결과로 주장하지 않아야 한다.

### Style Drift {#production-design-style-drift}

한 subject나 shot의 편의적 변경이 전체 visual language와 충돌하면 affected scope와 approved exception을 식별할 수 있어야 한다.
