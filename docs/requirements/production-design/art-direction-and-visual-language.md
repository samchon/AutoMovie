# Art Direction과 시각 언어

## 반복 적용 가능한 시각 원칙 {#production-design-art-direction}

Shape language, proportion, palette, material character, contrast, density, aging, graphic language와 composition tendency를 여러 subject와 location에 적용 가능한 project-owned 원칙으로 정의할 수 있어야 한다.

원칙은 적용 대상, 우선순위, 허용 변이, 예외 조건과 관찰 가능한 결과를 가질 수 있어야 한다. 단어 목록만 있고 어느 design 선택도 판정할 수 없는 art direction을 완료로 취급하지 않아야 한다.

### Reasoned Choice {#production-design-reasoned-choice}

각 핵심 원칙은 story, character, era, environment 또는 production constraint 중 무엇에 답하는지 설명하고 장식적 adjective 목록으로 끝나지 않아야 한다.

서로 충돌하는 readability, historical reference, mood, budget와 delivery constraint 사이의 선택은 우선한 가치와 양보한 결과를 기록할 수 있어야 한다. 편의적 선택을 의도된 style로 사후 포장하지 않아야 한다.

### 일관성과 차이 {#production-design-consistency-variation}

같은 세계의 shared language와 faction, character, place, time phase별 intentional difference를 함께 표현할 수 있어야 한다.

Variation은 어느 축을 공유하고 어느 축을 달리하는지, 범위와 seed 또는 선택 규칙이 필요한지 선언할 수 있어야 한다. 모든 대상에 동일한 색과 모양을 적용하는 것을 일관성으로 오인하지 않아야 한다.

### Reference에서 저작으로 {#production-design-reference-realization}

Reference의 구체적 관찰을 geometry, material, pattern, light, dressing와 state 선택으로 변환하고 reference likeness 자체를 결과로 주장하지 않아야 한다.

한 reference의 관찰을 여러 design unit이 사용할 때 각 consumer와 변환된 결정을 찾을 수 있어야 한다. Reference의 전체 style, 저자 정체성 또는 시대를 복제하라는 불명확한 지시를 충분한 design contract로 취급하지 않아야 한다.

### Style Drift {#production-design-style-drift}

한 subject나 shot의 편의적 변경이 전체 visual language와 충돌하면 affected scope와 approved exception을 식별할 수 있어야 한다.

### 시각 Hierarchy와 Readability {#production-design-visual-hierarchy}

Hero, supporting subject, background, landmark와 effect가 예상 viewing condition에서 서로 다른 visual priority를 가지도록 silhouette, value, color, detail와 motion contrast를 계획할 수 있어야 한다. 모든 detail이 같은 주목도를 요구하지 않아야 한다.

### Graphic Language와 화면 내 Text {#production-design-graphic-language}

Signage, symbol, emblem, map, interface, typography와 화면 내 text는 language, script, scale, placement, legibility, rights와 world context를 가질 수 있어야 한다. 임의 placeholder text와 읽을 수 없는 생성 글자를 승인된 graphic design으로 제시하지 않아야 한다.

### 시기와 State별 Visual Language {#production-design-phase-visual-language}

낮과 밤, 계절, damage, occupation, renovation, faction change와 story phase가 visual language를 바꾸는 경우 base identity와 phase override를 구분할 수 있어야 한다. Shot마다 새 palette와 material을 다시 선택해 continuity를 잃지 않아야 한다.

### 거리와 전달 조건 {#production-design-viewing-conditions}

Art direction은 delivery raster, 예상 camera distance, movement, lighting와 structural pass에서 어떤 shape, value와 detail이 살아야 하는지 선언할 수 있어야 한다. 확대된 concept image에서만 보이는 detail을 실제 film의 readability로 간주하지 않아야 한다.

### 예외 승인 {#production-design-art-direction-exceptions}

의도적 style rupture, dream state, archival segment와 다른 visual regime는 적용 범위, 이유, 진입과 종료 조건, continuity consequence를 가진 승인된 exception으로 표현할 수 있어야 한다. 예외가 전체 규칙을 무효화하거나 설명 없는 drift를 숨기지 않아야 한다.

### Art Direction Acceptance {#production-design-art-direction-acceptance}

검토자는 representative subject와 location에서 shared language, intentional variation, hierarchy와 phase change가 관찰되는지 current evidence로 판정할 수 있어야 한다. 미감의 유일한 정답을 강제하지 않되 선언한 원칙과 결과의 불일치는 finding으로 남겨야 한다.
