# Production Design 요구사항

Production design은 screenplay의 장소, 인물, 사물과 사건이 공유할 시각 세계, 실제 축척, material language, 상태, source authority와 제작 범위를 정의한다. 완성 asset과 시대별 style kit를 선제 제공하는 catalogue가 아니라 사용자가 필요한 대상을 만들거나 외부 자료를 provenance와 함께 채택하고, 배치하고, 예산화하고, 검증할 기준이다.
