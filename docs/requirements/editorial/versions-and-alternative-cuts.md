# Version과 Alternative Cut

## 동일 Source의 여러 Edit {#editorial-versions-alternative-cuts}

Rough cut, director-like authored cut, trailer, language version, accessibility version와 project-defined alternative를 common source, difference와 stable identity로 보존할 수 있어야 한다.

### Append-only Revision {#editorial-append-only-revision}

Published 또는 reviewed cut을 제자리에서 바꾸지 않고 새 edit version과 parent relation을 만들며 source와 receipt lineage를 유지해야 한다.

### Difference Report {#editorial-difference-report}

Clip order, range, transition, track, marker, effect, duration와 media reference 차이를 canonical order로 보고할 수 있어야 한다.

### Selection State {#editorial-selection-state}

Draft, candidate, selected, superseded와 rejected를 구분하고 선택되지 않은 alternative의 render와 review를 current film evidence로 사용하지 않아야 한다.

### Stale Review {#editorial-version-stale-review}

Edit version이 바뀌면 sequence와 film review, final render와 media probe를 stale로 만들고 unchanged source review의 freshness와 구분해야 한다.
