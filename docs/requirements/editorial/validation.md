# 편집 검증

## Timeline 구조와 완성 Film 검증 {#editorial-validation}

Edit는 rational time, source range, track composition, transition, picture·sound relation, continuity, coverage, duration와 final media를 검증해야 한다.

### Structural Validation {#editorial-structural-validation}

Gap, overlap, source overflow, handle shortage, cycle, missing media, invalid track와 duration mismatch를 canonical diagnostic으로 보고해야 한다.

### Story Coverage {#editorial-story-coverage}

Required scene, beat, semantic event, reaction와 state consequence가 selected source range에 남아 있는지 확인해야 한다.

### Sequence Review {#editorial-sequence-review}

연속 clip의 rhythm, transition, screen relation, sound continuity와 information order를 current assembled sequence에서 검토해야 한다.

### Film Review {#editorial-film-review}

전체 film의 story arc, pacing, audiovisual continuity, accessibility와 terminal state를 개별 shot review와 별도로 검토해야 한다.

### Result Status {#editorial-validation-status}

Compiled, conformed, rendered, probed, reviewed, failed, unsupported와 not-run을 구분하고 timeline file 존재만으로 finished film을 주장하지 않아야 한다.
