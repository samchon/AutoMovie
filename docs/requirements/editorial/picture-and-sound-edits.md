# Picture와 Sound Edit

## 서로 다른 경계를 가질 수 있는 Picture와 Sound {#editorial-picture-sound-edits}

Picture cut, dialogue, ambience, effect와 music의 in·out point를 독립적으로 저작하여 J-cut, L-cut, prelap, tail와 sound bridge를 표현할 수 있어야 한다.

### Emission과 Presentation {#editorial-sound-emission-presentation}

World sound의 emission·arrival와 timeline presentation range를 구분하여 picture trim이 event source time을 바꾸지 않아야 한다.

### Room Tone와 Ambience {#editorial-room-tone-ambience}

Location과 interior state의 room tone, ambience bed와 sustained source를 cut 경계에서 이어서 audible discontinuity를 검토할 수 있어야 한다.

### Dialogue Edit {#editorial-dialogue-edits}

Utterance, breath, pause, overlap와 interruption을 단어·audio timing과 actor performance에 연결하고 문장 중간 trim을 의도 없이 만들지 않아야 한다.

### Audio Boundary Refusal {#editorial-audio-boundary-refusal}

Truncated cue, missing tail, duplicated event, stale arrival와 unsupported time transform을 거부해야 한다.
