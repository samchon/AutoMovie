# Timeline 범위와 Identity

## Film Presentation의 정본 {#editorial-scope-identity}

Timeline은 stable identity, ordered tracks 또는 composition, film duration, timebase, source references, transitions, markers, effects와 delivery relation을 가져야 한다.

### Story와 Film Order {#editorial-story-film-order}

Story time의 causal order와 film에서 보여 주는 presentation order를 구분하여 flashback, intercut, montage와 replay를 표현할 수 있어야 한다.

### Source Preservation {#editorial-source-preservation}

Edit는 source shot, performance, sound와 event identity를 참조하며 trim과 placement를 원본 source의 state로 되돌려 쓰지 않아야 한다.

### Authored Cut {#editorial-authored-cut}

Shot order, duration, transition와 picture·sound relation은 사용자와 저작 에이전트가 소유하고 engine이 pacing을 임의 최적화하지 않아야 한다.

### Missing Timeline {#editorial-missing-refusal}

Unordered shot list, directory filename order와 render modification time을 finished film timeline으로 취급하지 않아야 한다.
