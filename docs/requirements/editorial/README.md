# 편집 요구사항

편집은 촬영 또는 생성된 소스 구간을 유리수 영화 시간선에 배치하여 관객이 보는 순서, 지속 시간, 화면과 소리의 관계를 결정한다. 소스의 사건과 상태는 보존하면서 선택 구간, 배열, 겹침, 전환, 버전을 명시적으로 기록해야 하며, 파일명 순서나 실행 시각 같은 우연한 상태가 완성본을 결정해서는 안 된다.

이 디렉터리는 시간 표현부터 최종 conform과 검증까지 한 편집본을 재현하고 비교하는 데 필요한 사용자 관찰 가능 계약을 정의한다. 자동 지표는 구조적 사실을 보고할 수 있지만 창작 판단이나 승인 자체를 대신하지 않는다.
