# 저작 계약 판별자

### Typed host and cardinality selection {#spec-authoring-production-evidence-contract-discriminators}

<!-- @evidence requirements/production-evidence/authoring-contracts.md#agent-production-evidence-contract-discriminators 저작 계약마다 독립적인 host 종류와 cardinality를 선택한다. -->

Contract registry는 target identity마다 domain, physical file, anchor, active status, applicable production kinds, host branch, symbol depth, relationship kind와 cardinality를 하나의 typed entry로 보존한다. Graph factory는 같은 registry를 validation, claim construction과 human-readable binding manifest에 사용하며 별도 target list를 유지하지 않는다.

Construction principle은 선택한 construction H2/H3/H4 각각의 checklist, obligation은 complete construction population account 또는 ordinary H2 coverage, upstream은 exact construction lineage, discovery는 draft-active audit, naturalness는 exact construction counterpart를 가진 final screenplay H2/H3/H4의 대사·내레이션·관객용 언어 checklist, source contract는 selected public export 관계로 투영한다. Final host는 construction의 외형, 형상, 재료, 배치, 물리 상태, 접촉, 동작, sound event와 timing 묘사를 동일하게 보존하며 이 영역을 naturalness claim으로 수정할 수 없다. Registry가 선택하지 않은 H2, inactive language rule, wrong-pass 또는 wrong-shape branch와 host-kind mismatch는 partial graph 없이 stable diagnostic으로 실패한다.
