## Interior space 명세 범위 {#interior-space-specification-scope}


이 명세 묶음은 건물 interior를 저작·해석·검증하는 package-independent 시스템 경계를 정의한다. 입력 계약, current 상태, 불변식, 파생 출력, 진단 가능한 실패와 revision 호환성을 기준으로 나눈다. 선박·항공기·우주선과 그 밖의 비건물 host 내부는 일반 공간 원리를 참고할 수 있지만 current 제품 지원 약속에는 포함하지 않는다.
