# 얼굴 파라미터와 편집

## 얼굴 저작의 시스템 경계 {#face-spec-boundary}

### 버전과 재생 basis {#face-spec-document}

<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-document 독립 문서의 basis, 버전과 결정론적 해석을 정한다. -->

얼굴 문서는 저작자 식별자와 schema 및 구성 규칙 버전, 입력 basis, 형태, 상세 제어, 비대칭, 외관과 표정으로 구성한다. basis의 길이 단위는 mm이고 +Y는 위, +Z는 얼굴 전방, +X는 해부학적 왼쪽이다. 관측 cage를 사용하는 경우 topology, landmark 의미와 관측 표정이 같은 버전에 속해야 한다. 단안 깊이와 뒷면은 추정으로 구별한다. 구성은 외부 사진, fitting runtime, 현재 편집 이력 또는 난수에 의존하지 않는다. 미지원 버전과 누락되거나 유효하지 않은 basis는 구성 전에 거부한다.

### 부품과 표면 구성 {#face-spec-components}

<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-anatomical-components 이름 있는 부품, 단면과 공유 표면의 기하적 의미를 정한다. -->

각 부품은 명명된 부착점, 국소 형상, 표면 경계, 필요하면 내부 구조와 재질을 소유한다. 두개골과 목은 얼굴의 경계를 이어 닫힌 피부와 의도한 목 crop을 만들고, 귀는 최종 두부 표면에 부착한다. 눈꺼풀과 입술은 고리와 단면을 통해 주변 피부에 이어지며 안구, 각막, 비강 입구와 치열은 그 부품의 기준에서 배치된다. 곡선 보간, 표면 분할과 공통 법선은 동일한 topology에서 계산한다. 렌더 모델 경계에서만 mm를 m로 변환한다.

선택적 최종 국소 코 단면은 부품 fitting 때 깊이 축척과 기본 돌출을 적용한 기준점에 타원체 앞면과 접선을 고정한다. 같은 단면식을 세분화·피부 층 처리 뒤의 실제 정점에서 평가하며, 기존 제어 단계 단면이나 완전한 loft와 겹치지 않는다. 실제 skin/lining 경계의 거리 d와 연결 폭 w에서 t=min(1,d/w)의3t²-2t³으로 연결하고 안감 정점은 움직이지 않는다. 팁 기준점에서 정점의 Z 거리와 양의 깊이 범위의 비를 z라 하면, 깊이 비중은 s=min(1,2(1-|z|))의3s²-2s³이고 |z|>=1은 영점이다. 범위 절반 안에서는 단면 목표가 깊이 비중으로 약해지지 않고 후면은 제외한다. 다른 기존 최종 코 형상은 종전 깊이 비중을 유지한다. 빈 단면 배열은 변위 영점이며 기준점과 배열은 입력 변경으로 달라지지 않는다. 경계의 기존 접선을 보존하므로 틀린 콧구멍 접선이나 전역 충돌을 고쳐 준다고 주장하지 않는다.

최종 코 형상의 additive station, section loft, local lobule은 서로 다른 대안이다. 상세 계층이 다른 대안의 필수 키를 하나 명시하면 이전 대안의 payload 전체를 교체하고 연결 폭과 깊이 범위는 보통의 상속을 유지한다. 같은 대안 안의 부분 필드는 기존 값을 상속한다. 한 입력에서 둘 이상의 대안을 함께 선언한 것은 명확한 선택으로 취급하지 않고 기하 구성에서 거부한다.

선택적 연결 코 외피는 원래 개구부 순서에 대응하는 완전한 배열이다. 각 개구부의 엄격히 증가하는 둘레 위상은0부터 시작해1미만이며, 양의 외측 폭(mm), signed crest 높이(mm), 폭 안쪽의 crest 위치 비율(0,1), 독립 cavity 축에 수직인 개구 평면의 외향 방향에서 단면 법선 쪽으로 회전하는 signed roll(도)을 정한다. 위상은 원래 절개 경계의 시작 정점과 winding에 고정한 edge ordinal 비율이며 호 길이가 아니다. 단면값은 주기적인 cubic smoothstep으로 연결하고, 외피의 두 Hermite 구간과 전정의 입구는 같은 물리 접선을 공유한다. 각 구간의2~64개 샘플은 기하 해상도 범위이지 해부학적 치수가 아니다. 주변 피부를 같은 전체 외피로 지지해 세분화한 뒤 예약 영역을 교체하고, 원래 정점의 세분 경계 계보를 확인해 실제 외측 부착 좌표는 보존한다. 안감의 축과 깊이는 회전된 기존 cavity offset이 단독 소유한다. 빈 배열과 생략은 이전 경로이며, legacy rim section/curve 또는 접선을 다시 바꾸는 final body와 중복 선택은 거부한다.

안구 구면의 중심 깊이를 맞추는 방향은 눈구석·상하 눈꺼풀의 평면 또는 기록된 관측 광선에서 명시적으로 선택한다. 생략과 평면 선택은 기존 계산을 유지한다. 관측 광선 선택은 경계 표본 평균의 투영 위치를 고정하고 그 광선 방향의 평균 구면 잔차로 중심 깊이를 맞춘다. 어느 방식도 현재 시선·눈 감음 또는 홍채 표식을 중심의 기준으로 사용하지 않는다. 유효한 상하 경계와 관측 방향, 충분한 반경이 필요하며 구면을 벗어난 접촉선을 억지로 붙이지 않는다. 반경과 중심은 저작된 표면 근사이며 해당 인물의 안구 치수 측정을 뜻하지 않는다.

선택적 방사형 광학 좌표계는 원점에 놓인 같은 반경의 구면과 국소 +Z축 주위에서 홍채·동공·각막을 구성한다. 국소 +Z를 안구 중심에서 관측 홍채의 구면 교차점으로 향하는 방향에 최단 회전시킨 뒤 안구 중심으로 평행 이동한다. 국소 치수와 각막의 앞뒤 두께를 보존하고 현재 시선 회전은 그 뒤에 같은 안구 중심을 기준으로 적용한다. 전체 limbus와 각막 접촉을 요구하며, 표정 수행을 생략해도 완전한 안구와 광학 층을 유지하고 피부로 가린다. 접촉과 렌더가 같은 각막 생성과 강체 배치를 사용한다. 생략 또는 머리 평면 선택은 기존 XY 높이장 계산을 유지한다. 유한한 양의 반경과 중심이 아닌 유한한 축 표본이 필요하다. 이 선택은 안구와 두개골 사이의 전역 충돌 해결이나 사진에서 가려진 광학 축 복원을 보증하지 않는다.

위눈꺼풀의 일반 단면은 margin, tarsal, creaseInner, creaseOuter, hood, preseptal의 양의 유한 offset을 엄격한 증가 순서로 검사한다. 선택적 완전 감김 단면은 동일한 종방향 witness와 attachment를 가진 완전한 배열이다. 이를 제공한 관측 단면은 hood만 crease 안쪽으로 돌아올 수 있고, hood는 margin과 preseptal 사이에 머문다. 모든 단면의 유한 projection과 모든 점보다 바깥의 attachment를 검사한다. 되접힘 단면의 offset/projection 곡선은 공통 평면 교차 계산으로 자기교차·접촉을 거부하며, 종방향 보간 결과도 실제 조회 때 검사한다. 기본 검사를 제거하거나 음영 무늬를 실제 가림으로 간주하지 않는다. 이 검사는 단면의 유효성이며 최종 공통 분할 곡면의 전역 무충돌 증명이 아니다.

목 단면의 폭·앞뒤 반경·축과 별개로 턱밑 전방 볼륨을 선택할 수 있다. 저작량 p는0..40mm이며 생략과0은 기존 형상을 유지한다. collar에서 upper section까지의 기존 곡선 진행도 t와 앞축 기준 단면각 θ에서 Z에 p·16t²(1-t)²·max(0,cosθ)²를 더한다. 연결 양 끝의 위치와 일차 접선, X/Y 좌표, 후면과 아래쪽 고리는 바꾸지 않는다. 공통 분할 전에 구성하고 새 두부 조직의 표정 변형을 함께 적용한다. 이 수치는 지방 두께나 연령의 측정값이 아니며 결합된 곡면의 구성 검사를 대신하지 않는다.

선택적 윗속눈썹 프로파일은 최종 위눈꺼풀 경계에 뿌리를 유지하면서 최대 중심선 길이, 전방 기준 시작 각도, 끝까지의 회전각, 좌우 퍼짐, 뿌리 반지름, 끝 가늘어짐과 결정론적 길이 변화를 구별한다. 중심선은 일정 곡률 arc이고 0도 curl은 직선이다. 곡률 변화가 중심선 길이를 바꾸지 않으며 눈구석과 개별 성장 비중은 최대 길이에서 가닥을 줄인다. 좌우 퍼짐은 해부학적 부호를 반전한다. 길이는 투영 높이나 전방 도달거리가 아니고 저작 각도는 관측 표정의 두부 좌표계 기준이다. 표정은 뿌리를 최종 눈꺼풀에 운반하고 관측 개구부와 현재 개구부를 같은 안구 구면에 투영한 방사 방향 사이의 최단 회전으로 가닥 방향도 운반한다. 시선만 바뀌면 이 회전을 추가하지 않는다. 회전은 현재 뿌리를 중심으로 하여 길이와 단면을 유지한다. 방사축 주위 비틀림, 모발 물리와 가닥 사이 충돌은 이 강체 근사에 포함하지 않는다. 영벡터, 비유한 방향과 유일한 최단 회전을 정할 수 없는 정반대 방향은 거부한다. 프로파일 생략은 기존 짧은 속눈썹을 정확히 유지하고 선택 시 일곱 값을 모두 제공한다.

정적 모발 카드는 head 공간의 root-to-tip 가이드와 폭 방향, 폭 및 끝 비율로 구성한다. 두피 위치가 바뀌면 저작 가이드의 부착을 다시 검토한다. 카드의 longitudinal 분할과 무늬로 표현하는 가닥 수는 독립적이며 무늬 수의 증가가 삼각형을 추가하지 않는다. 무늬와 투명도는 결정론적 PNG와 UV0으로 전달한다. 눈썹의 면 표현도 최종 피부 깊이와 법선을 조회하고 현재 눈썹 경계를 따른다.

기존 단일 모발과 별도로 최대 여덟 개의 명명된 모발층을 저작할 수 있다. 각 층은 완전한 카드 프로파일을 가지며 폭·밀도·색상 무늬·법선·가이드를 다른 층과 독립적으로 정한다. 층 수와 층별 기존 1,024개 카드 한도는 저작 비용 한도이지 생물학적 밀도가 아니다. 추가 층 배열은 완전 교체하고 빈 배열은 추가 층만 제거하며 기존 단일 모발을 바꾸지 않는다. 생략은 기존 출력을 유지한다. 층 이름은 공백만으로 구성할 수 없고 빈 카드층을 포함해 중복을 거부한다. 빈 카드층의 잘못된 프로파일은 계속 거부하지만 사용하지 않는 재질은 생성하지 않는다.

각 비어 있지 않은 층은 독립된 mesh와 파생 재질을 소유한다. 기본 재질은 입력의 resident palette에서만 찾고 앞선 층의 생성 재질을 기본 재질로 빌리지 않는다. 파생 재질 identity가 입력 또는 다른 생성 재질과 충돌하면 거부한다. 순서를 바꾸면 배열 순서만 바뀌고 같은 이름의 층이 갖는 형상과 재질 값은 유지한다. 기존 단일 모발의 part 및 재질 identity는 보존한다.

선택적 모발 법선 강도는 0부터 1까지의 저작 비율이다. 무늬의 각 표본을 소유한 가닥의 중심과 폭에서 원형 횡단면의 접선 공간 법선을 만들고 선형 RGB PNG로 전달한다. 기하와 alpha 무늬는 바꾸지 않는다. 생략과 0은 기본 재질의 기존 normal binding을 유지하며 양수는 파생 카드 재질에만 생성 normal binding과 강도를 적용한다. 이 근사는 개별 가닥의 실루엣, 지름 측정이나 물리적 산란을 제공하지 않는다.

모발 RGB 무늬의 명암 강도는 투명도, 법선과 기하와 독립적인 [0,1] 값이다. 1과 생략은 기존 PNG bytes를 유지하고 0은 모든 RGB를 흰색으로 만들어 기본 재질만 색을 정한다. 중간 값 s는 기존의 양자화 전 encoded RGB 값 c를 1-s(1-c)로 바꾼 뒤 8-bit로 양자화한다. alpha는 그대로다. 이 값은 색소량이나 물리적 반사율의 선형 보간이 아니다. 빈 모발 집합도 비유한 값과 범위 위반을 거부한다.

선택적 곱슬 무늬 프로파일은 UV 폭 대비 최대 횡진폭 [0,0.5], 길이 방향의 명목 반복 수 [0,16], 법선 방향에 사용하는 명목 카드 폭/길이 비율 [0.01,100]을 모두 제공한다. 결정론적 시드가 가닥의 위상, 진폭 및 반복 수를 변주하며 무늬는 512 정방형 PNG로 구성한다. alpha와 법선은 같은 가닥 중심과 횡단면을 사용하고, 법선의 횡방향을 무늬의 접선에 수직으로 회전한다. 명목 비율은 저작 값이며 서로 다른 카드의 실제 치수를 자동 복원하지 않는다. 프로파일은 가이드나 삼각형을 바꾸지 않고 그려진 모발의 점유 영역과 음영을 바꾼다. 생략은 원래 무늬의 크기와 bytes를 유지하며 0 진폭이나 0 반복을 명시하는 것은 새 직선 무늬이지 생략과 같은 뜻이 아니다. 빈 모발 집합도 프로파일의 비유한 값, 누락과 범위 위반을 거부한다.

입술 접촉선 깊이는 몸통 부피와 개구부 높이에서 독립적으로 조절한다. 양쪽 안쪽 경계를 같은 전방 거리만큼 이동하고 바깥 홍순 경계와 입꼬리에서는 변위를 0으로 유지한다. 닫힌 위아래 경계의 일치는 보존하며 생략은 기존 깊이를 유지한다.

선택적 구강 벽 비율은 [0,0.95]의 저작 비율이며 생략하면 기존의 분리된 구강 뒷면을 유지한다. 명시적 0은 입술 경계부터 즉시 좁아지는 연결된 안쪽 면이다. 진행도 v가 입술 경계 0에서 후방 끝 1로 갈 때 깊이는 명목 구강 깊이의 1.8배·v이며, 반경 비율은 cos(pi/2·max(0,(v-wall)/(1-wall)))다. 명목 깊이는 양수이고 최대 깊이도 유한해야 한다. 첫 고리부터 24개 고리를 등간격으로 놓고 후방 끝은 경계 평균 XY 및 평균 Z에서 최대 깊이만큼 물러난 단일 정점으로 닫는다. 이 비율은 구강 해부 측정값이 아니라 독립적인 형상 저작 envelope다. 완전히 닫힌 수행 입술에서는 퇴화한 내부 면을 만들지 않지만 선택한 수치의 범위는 계속 검사한다.

선택적 내부 공간은 명시적 연결 벽과 함께 제공하며, 가로·세로 확장량은 유한한 비음수 mm, 전이 깊이는 유한한 양수 mm다. 경계 평균 c와 각 축의 최대 절대 편차 e에 대해 기존 고리의 X/Y에 r·s·(p-c)/e·확장량을 더한다. r은 기존 후방 반경 비율이고 s=t²(3-2t), t=min(1,1.8·깊이·v/전이깊이)다. 실제 첫 경계와 후방 끝은 그대로 유지하고 깊이 좌표나 치열 배치는 바꾸지 않는다. 생략과 두 확장량 0은 기존 메시와 같고, 비영점 확장은 두 축의 양의 유한 투영 범위를 요구한다. 최종 좌표의 비유한 값은 거부한다. 독립 수치 편집의 범위는 확장 0..30mm와 전이 0.1..60mm이며 이 범위는 편집 envelope이지 해부학적 정상치나 결합 형상의 비관통 보증이 아니다.

안구 깊이는 주변 피부 부착의 이동과 독립적으로 저작한다. 양의 mm는 정규화한 관측 방향을 따라 안구 전체를 관측 카메라 쪽으로 옮기고 음수는 반대로 옮긴다. 바깥 눈꺼풀과 피부의 적합 목표는 함께 평행 이동하지 않으며 안쪽 접촉은 새 광학 표면을 따른다. 공통 분할과 최종 광학 접촉은 출력 피부를 다시 계산하므로 주변의 모든 정점이 고정된다는 뜻은 아니다. 크기를 다시 적합하거나 표정마다 깊이를 중복 가산하지 않는다. 생략과 명시적 0은 기존 적합 결과를 유지하고 좌우는 독립적이다. 이 값은 정체성 깊이 제어이며 임상 측정값이나 단안 복원 사실이 아니다.

양측 위안와 기반 깊이는 부품 적합 전에 공유 host에 적용하는 별도의 정체성 제어다. 양의 mm는 전방, 음수는 후방이며 범위는 [-8,8]의 저작 envelope다. 원래 관측 basis와 눈의 개구부 좌표는 보존하고 눈꺼풀의 외곽 부착은 변경한 기반에서 다시 적합한다. 영향은 두 눈의 가장 높은 개구부보다 0.5mm 위에서 시작해 각각의 아래 눈썹 경계 평균 높이에서 최대가 된다. 그 높이 차이의 두 배만큼 위로 가면 다시 0이다. 횡방향은 각 아래 눈썹 범위에서 최대이며 개구부 폭의 1/4인 양쪽 shoulder에서 0으로 줄어든다. 각 fade는 cubic smoothstep이고 양쪽 영향이 겹치면 합이 아닌 최댓값을 쓴다. 두 눈의 resident 부착과 비퇴화한 상부 band가 필요하며 생략과 0은 이 추가 부착 조건 없이 기존 기하를 유지한다. 이 제어는 표정의 눈썹 높이나 조립 후 피부 relief와 다르며 뼈 두께의 측정값을 뜻하지 않는다.

선택적 위눈꺼풀 단면은 margin, tarsal body, 주름의 두 경사면, hood와 preseptal 이행부를 독립적인 거리와 전방 relief로 정한다. 여섯 거리는 개구부에서 피부 방향으로 엄격히 증가하고 피부 부착 거리는 그 바깥에 놓인다. 해부학적 안쪽 0에서 바깥쪽 1까지 2~32개 단면을 같은 볼록 보간으로 연결해 순서를 유지한다. 눈구석으로 갈수록 기본 단면에 sine 비중으로 접합하고 개구부와 광학 크기는 이 단면이 바꾸지 않는다. 생략하면 기존 기본 수식을 유지하며 상세 단면에 기본 주름 부피를 중복 가산하지 않는다.

선택적 눈썹 방향장은 해부학적 안쪽 0부터 바깥쪽 1까지 2~32개의 완전한 표본을 갖는다. 각 표본은 저작한 뿌리 band의 아래쪽과 위쪽에서 시작하는 가닥의 끝 위치(눈썹 아래 경계 0, 위 경계 1)와 signed lateral bend(mm)를 따로 정한다. 길이 방향은 cubic smoothstep, 뿌리 band 내부는 선형으로 보간한다. band가 한 위치로 줄면 두 방향의 중간을 사용한다. 이 방향은 기존 span과 outward bend를 대체하되 생략 시 기존 수식을 유지한다. 가닥 수와 분할, 뿌리 밀도, 최종 피부 부착과 좌우 부호는 그대로이며, 길이가 0이 되는 실제 가닥은 거부한다.

선택적 눈썹 밀도 시드는 0부터 2^32-1까지의 정수다. 시드가 있으면 뿌리 높이와 다른 결정론적 수열로 끝부분의 남는 가닥을 선택하며 각 가닥의 위치와 단면은 바꾸지 않는다. 끝 밀도 감소가 없으면 시드도 형상을 바꾸지 않는다. 생략하면 기존 문서의 정확한 재생을 위해 원래 결합된 분포를 유지한다. 그 기존 분포는 성긴 끝부분의 특정 뿌리 높이를 비울 수 있으므로 독립 분포를 원하는 새 저작은 시드를 명시한다.

선택적 혀는 국소 +X 가로, +Y 위, +Z 앞의 mm 좌표계에서 닫힌 몸통으로 구성한다. 진행도 v가 앞끝 0에서 뒤끝 1로 갈 때 단면 반경은 sin(pi*v), 길이 좌표는 -length*v다. 반폭 [5,35]mm, 길이 [20,70]mm, 반두께 [2,15]mm, 관측 혀등 상승 [0,15]mm를 각각 저작한다. 원주 각도 a의 X는 반폭·반경·cos(a), Y는 반두께·반경·sin(a)와 혀등 상승·반경²의 합이다. 중앙 홈은 깊이 [0,3]mm와 Gaussian 가로 폭 [0.2,8]mm를 쓰고 윗면만 낮춘다. 홈 깊이는 반두께보다 작아야 한다. 31개 고리의 48개 표본과 단일 앞·뒤 정점을 연결하고 법선은 실제 결과에서 계산한다.

혀의 관측 배치는 하순 중앙과 양쪽 입꼬리의 직교 좌표계를 사용한다. 입꼬리 현이 X를 정하고 독립 위쪽 가이드에서 X 성분을 제거해 Y를 정하며 Z는 X cross Y다. 이 변환을 치열과 공유하고 부품의 크기는 바꾸지 않는다. 하순 중앙에서 아래 이동 [0,15]mm와 뒤 이동 [0,30]mm를 별도로 저작한다. 비유한 점·offset, 퇴화한 좌표계, 불일치한 법선 버퍼와 표현 가능한 범위를 넘는 출력은 거부한다. 재질은 존재하는 명시적 ID를 사용하고 생략된 부품은 팔레트를 바꾸지 않는다. 이 수치 한계는 편집 envelope이며 생물학적 정상 범위가 아니다.

### 피부 상태와 국소 분할 {#face-spec-skin-condition}

<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-skin-condition 지속적인 피부 형태와 표정 주름의 제어, 부착과 분할을 구분한다. -->

피부 상태는 공유 얼굴 표면에 적용한다. 느슨함은 0~1의 저작 비율이며 지속 주름의 깊이와 부위별 강도를 곱해 휴식 상태의 relief를 정한다. 이마, 미간, 눈꼬리, 하안검, 팔자, 입꼬리 아래와 입 주위의 이름 있는 곡선은 현재 양측 눈·눈썹·입 부착점과 실제 전방 피부 깊이에서 생성한다. 눈 밑 주머니, 볼·턱선 처짐과 부피 감소는 넓은 표면 변위로 따로 정한다. 양측은 동일 강도에서 각자의 부착점을 사용하며 이 피부 상태 집합은 좌우 공통 제어다. 표정 주름 강도는 현재 눈썹 올림·내림, 눈 감김, 미소와 입 오므림의 해당 채널에서만 추가 relief를 만든다. 표정 영점은 이 추가량을 만들지 않는다.

피부 상태 생략은 느슨함과 표정 주름 강도가 모두 0인 기본값으로 해석한다. 이때 다른 표면층을 추가로 분할하거나 기존 얼굴을 바꾸지 않는다. 좁은 주름이 있는 영역은 그 층의 유효 field와 교차하는 삼각형만 폭에 비례한 간격으로 세분하고 인접 면과 새 정점을 공유한다. 기존 정점과 material region을 보존하며 내부 모서리의 추가 표본은 양 끝의 접평면으로 곡률을 보간한다. 열린 경계는 선형 중점을 사용하고 최종 변위의 기존 경계 감쇠를 유지한다. 정확히 일치한 자유 경계 표본은 아직 접합하지 않은 조직 접촉으로 취급한다. 해당 표본에 접한 면은 공통 분할의 해상도를 유지하여 두 접촉면과 입꼬리의 반대쪽 접힘에 서로 다른 추가 분할이 생기지 않게 한다. 주변의 일반 피부와 실제 열린 경계는 계속 세분한다. 이 보간은 없던 해부학적 사실을 복원하는 절차가 아니다. 비유한 값, 허용 범위 위반과 표현 가능한 중점을 만들지 못하는 간격은 거부한다.

### 기준 조직 좌표의 피부색 {#face-spec-skin-colour}

<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-skin-colour 색과 조명·형상을 구별하고 기준 조직에 붙은 지역색의 저장 및 표정 운반을 정한다. -->

지역색은 고유한 비어 있지 않은 이름, 기준 host 정점 ID, mm 단위 XYZ offset과 양의 반경, [0,1] 선형 RGB gain 및 [0,1] 강도를 가진다. 기준점은 identity frame 적용 후, 현재 표정 적용 전의 좌표다. 정규화 거리 r가 1 미만이면 w=strength·(1-r)^4·(4r+1), 채널별 곱은 1+(gain-1)·w이며 그 밖에서는 항등 흰색이다. 이름 순서대로 각 곱을 적용한다. 생략은 상속, 빈 배열은 지역색 제거다. 비유한 좌표·값, 없는 anchor, 중복 이름, 비양수 반경과 범위 밖 gain/강도는 거부한다.

관측 기준과 현재 표정의 component cage는 동일한 정점·삼각형·재질 영역 대응을 유지한다. 기준 XYZ는 현재 XYZ와 같은 Loop mask를 거치고 적응적 edge 삽입에서는 양 끝 기준 좌표를 선형 보간한다. 비선형 색 함수는 이 세분된 기준 좌표에서 평가한다. 기하 최종 보정은 기준 좌표를 움직이지 않는다. 두 조직이 접촉해 기하 정점을 합칠 때 원래 삼각형 corner의 색을 보존하고, 출력은 색 seam의 정점만 나누되 공통 기하 법선은 유지한다. 색 함수 자체는 표정이나 조명을 읽지 않으며 대응 위상이 달라지면 임의 최근접점으로 대체하지 않고 거부한다.

### 해석과 교체의 불변식 {#face-spec-controls}

<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-controls-replacement 기본값, 상세 override와 배열 교체의 순서 및 부위 보존을 정한다. -->
<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-anatomical-components 각 제어의 해부학적 의미와 단위, 부착 및 좌우 규칙을 요구한다. -->

해석은 고정된 버전 기본값, basis의 부품 설정, 중간 제어, 명시적 상세 설정, 좌우 설정, 표정 순서로 평가한다. 배열과 객체 배열은 요소별 암묵적 병합 없이 제공된 집합으로 교체한다. 생략은 앞선 단계의 값을 상속하고 앞선 값도 없으면 해당 버전의 기본값 또는 선택적 부품의 부재를 유지한다. 명시적 빈 배열은 해당 선택적 집합이 없는 상태를 뜻한다. 모든 제어는 단위, 기준과 허용 범위, 증가와 감소의 효과, 좌우 규칙과 부착 대상을 가진다. 중간 값과 상세 설정을 함께 적용한 최종 값도 검사하며 비유한 값, 부적합한 순서, 중복 identity와 불가능한 기하를 거부한다. 입력 문서와 호출자의 배열은 변형하지 않는다.

추가 모발층은 이름을 선택한 뒤 기존 단일 모발과 같은 단위와 범위의 수치를 편집한다. 선택 자체는 문서를 바꾸지 않는다. 한 수치 편집은 현재 저작된 추가 층 집합을 완전한 상세 배열로 복사한 뒤 선택한 층의 한 필드만 바꾸며, 다른 층의 생략된 값과 가이드 및 기존 단일 모발은 보존한다. 표시할 때 각 적용 프로파일의 생략된 법선 강도·taper 시작·RGB 명암 강도는 각각 0·0·1로 해석하지만 그 표시 기본값을 다른 층의 저작 값으로 저장하지 않는다. 없는 층과 모발 외 채널은 거부한다. 단일 수치의 상속 제거는 제공하지 않으며 전체 층 영역의 상속이 basis 집합을 복원한다.

저작 코드가 같은 객체를 basis와 상세 또는 여러 좌우·모발층에 공유하더라도 한 수치 편집이나 상속 제거는 선택한 소유자에만 적용한다. 공유 참조는 다른 소유자의 값을 함께 편집하라는 뜻이 아니다. 편집 결과는 선택한 경로의 컨테이너를 분리하며 다른 소유자의 저작 값과 호출자 입력을 보존한다.

### 공유 접합과 내부 구조 {#face-spec-attachments}

<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-controls-replacement 교체된 피부와 인접 부품이 하나의 경계를 사용하게 한다. -->
<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-expression 표정에서도 피부와 내부 기관의 접촉 및 가림 관계를 유지한다. -->

모든 부품은 같은 변경 전 host에 적합한다. 피부 제약을 함께 해석하고 겹치는 cut 소유권은 거부한다. 부품은 공유 vertex 또는 명시적 접합 correspondence를 사용하며 분할 후 최종 표면에서 내부 구조와 접촉을 계산한다. 경계는 별도의 복제 계산으로 추정하지 않는다. 부위 교체는 다른 부위의 저작 값을 유지하지만 경계의 파생 위치, 공통 법선과 접촉은 새 결과에서 재평가한다. 열린 목 crop과 명시적 기관 개구부 외의 피부 구멍, 잘못된 winding과 퇴화 삼각형은 유효한 결과가 아니다.

연결된 구강 안쪽 면은 최종 홍순 삼각형의 자유 경계 중 구강 seed가 속한 방향 있는 고리를 사용한다. 홍순 바깥 경계가 별도로 존재해도 seed로 고리를 구별하며, 원래 landmark 사이의 보간으로 분할 정점을 다시 추정하지 않는다. 첫 고리 좌표는 최종 피부에서 그대로 복사하고 연결 모서리의 방향은 피부와 반대로 둔다. 불완전하거나 비resident인 삼각형, 반복 정점, 비다양체 또는 같은 방향의 내부 모서리, 분기 경계, 자유 경계 밖의 seed, 비유한 경계 좌표와 길이 0인 경계 모서리는 거부한다. 출력이 표현 가능한 수치 범위를 넘는 경우도 거부한다.

예약된 안와 피부 연결은 원래 피부의 내부 높이 표본을 유지하는 방식을 선택할 수 있다. 이 방식은 허용된 외곽과 안쪽 경계를 유지하면서 내부 대각선을 재배치하고 공통 분할에 전달한다. 원래 지지 표면이 없는 위치나 표현 가능한 내부 삼각형을 만들 수 없는 좌표는 연결 전 거부한다. 생략된 기존 연결 방식을 암묵적으로 바꾸거나 광학 크기를 조절하지 않는다.

### 표정과 광학 기준 {#face-spec-expression}

<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-expression 관측 표정, 무표정 정체성과 재생 표정의 분리 및 광학 기준을 정한다. -->

표정 영점은 무표정이다. 관측 표정이 있는 basis는 그 표정을 제거한 정체성 기준과 현재 표정을 명시적으로 연결한다. 눈꺼풀 제어는 안구 크기나 각막 곡률을 재적합하지 않고, 시선은 안구 기준 안에서 움직인다. 좌우 눈꺼풀과 눈썹은 독립 채널이다. 입꼬리, 입술과 턱 움직임은 상악과 하악 치열의 부착과 구강 가림을 함께 평가한다. 해석기가 지원하는 채널과 조합은 문서화하며 그 범위 밖의 요청은 명명된 오류를 반환한다.

명시적 완전 감김 단면이 있는 위눈꺼풀은 같은 이름의 조직 offset과 projection을 관측 값에서 감김 값으로 (현재 폐쇄율-관측 폐쇄율)/(1-관측 폐쇄율)만큼 선형 이행한다. 관측 폐쇄율은 기존0..0.95 범위다. 관측과 같을 때 원래 값을 유지하고 더 열 때는 같은 식으로 외삽한다. attachment는 바꾸지 않는다. 실제 조회되는 단면의 순서·유한성·자기교차를 검사하여 유효하지 않은 중간 또는 외삽 상태를 거부한다. 감김 단면을 생략하면 이전의 조직과 표정 계산을 유지한다.

하악의 관측·현재 각도가 다르면 두개부와 목을 참조 좌표에서 구성한 뒤 새로 연결되는 피부에 운동을 적용한다. 이미 수행된 얼굴·입술의 공유 정점은 다시 회전시키지 않는다. 참조 복원은 실제 하악 피부 제약이 소유한 정점에 한정하고 현재 좌표의 하악 회전을 역변환하여 다른 호환 변위를 버리지 않는다. 공통 분할과 법선은 연결 및 수행 후 계산한다. 참조 목 단면의 기존 순서 검사는 유지하며 수행된 턱이 그 정적 단면 높이 아래로 움직였다는 이유만으로 목 치수를 다시 저작하지 않는다.

관측 상·하 입술 중앙의 높이 차이를 최소 4mm의 band로 삼아 하악 가중치를 cubic smoothstep으로 연결한다. band 바깥은 각각 0 또는 1을 유지한다. 완전 하악 가중치가 있는 관측 하부 얼굴의 최저 높이를 chin, hinge에서 그 정점들로 향하는 최대 하방 극각을 front로 정한다. 부착은 hinge 앞이면서 아래이고 하부 목보다 높아야 한다. 관측·현재 각도가 같으면 추가 조립 경로를 사용하지 않는다.

새 두경부 피부는 hinge 뒤와 하부 목 이하를 고정한다. 나머지 점은 hinge 기준 yz 반지름 r과 전방에서 아래로 증가하는 극각 theta를 사용한다. 완전 회전 영역의 끝은 a=min(front,asin(min(1,(hingeY-chin)/r))), 고정 영역의 시작은 b=asin(min(1,(hingeY-lowerNeckY)/r))다. theta<=a인 점은 기존 oral-band 가중 회전을 그대로 따른다. a<theta<b인 점에서는 d=현재·관측 각도 차이의 radians·oralWeight, L=b-a, s=1-d/L, u=(theta-a)/L을 사용한다. 양수 유한 s가 없으면 고정 경계까지의 회전 여유가 부족하므로 거부한다. 회전량은 d·(1-u)²·(s+2u)/(s+2(1-s)u(1-u))이며 완전 하악 가중치 구간에서 양끝 각도 미분은1이다. 가중치가 변하는 oral band의 얼굴 쪽 끝은 기존 가중 회전의 미분을 이어받는다. 완전 하악 가중치의 하부 구간은 반지름과 각도 순서를 유지하여 Cartesian 가중치 곱이 만드는 국소 방향 역전을 피한다. 이는 명시적 피부 kinematics이며 oral band 전체의 비접힘, 관절 활주, 근육 역학이나 전신 자기 충돌 해석을 보장하지 않는다.

혀등 상승과 앞쪽 이동은 각 [-8,8]mm이고 생략은 영점이다. 관측·현재 차이를 국소 몸통에 적용한다. 혀등 상승 비중은 sin(pi*v)²이고 앞쪽 이동 및 하악 회전 비중은 1-v²(3-2v)다. 앞쪽은 하악에 전부 따르고 뒤끝은 고정된다. 음의 관측 상대 전진으로 길이 좌표가 역전되지 않도록 length > 1.5·max(0,-advanceDifference)를 요구한다. 관측·현재 하악 각도 차이는 명시된 hinge를 중심으로 적용하며 비강체 수행 뒤 법선을 다시 계산한다. 혀를 선택하면 hinge가 필요하고 혀가 없으면 비영점 혀 표정을 거부한다. 입술의 분리·미소·오므림만으로는 혀를 이동하지 않는다. 이 가중치는 저작한 운동 근사이며 설골·근육·일반 조직 충돌을 해석하지 않는다.

### 편집 트랜잭션 {#face-spec-editor}

<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-editor-state 검증된 문서만 commit하고 이전 비동기 결과와 실패를 격리한다. -->

편집 상태는 마지막 유효한 문서, undo/redo 이력, 현재 요청 세대와 구성 상태를 가진다. 입력 파싱, 해석과 구성을 완료한 동일 요청만 문서와 표시 모델을 함께 commit한다. 새 요청 이후 도착한 이전 성공이나 오류는 현재 상태를 바꾸지 않는다. 실패는 오류를 표시하되 유효한 문서와 모델을 유지한다. 문서 불러오기, 부위 교체, 프리셋, 초기화와 이력 이동도 같은 검증 경로를 따른다. 카메라, 확대와 clay는 저작된 정체성 값을 바꾸지 않는다.

### 정적 얼굴 교환 {#face-spec-export}

<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-export 정적 얼굴 GLTF와 GLB의 단위, 재질, 변환 및 유효성을 정한다. -->

정적 얼굴 export는 m 단위 mesh와 material group, transform, 선형 색과 금속성 및 거칠기, 지원하는 광학 extension을 보존한다. Float32 출력 경계에서 퇴화, topology와 광학 volume을 다시 검사한다. 지원하지 않는 texture resource, bone binding이나 animation을 손실 없이 변환할 수 없으면 거부한다. GLTF와 GLB는 같은 검증된 document를 직렬화한다. 파일시스템과 browser 다운로드는 이 문서 변환과 분리된다.

선택적 정점별 선형 RGB는 COLOR_0 VEC3 Float32로 내보낸다. 한 material group에서 유색 부품과 무색 부품을 합칠 때 무색 부품에만 항등 흰색을 채운다. 색이 전혀 없던 그룹에는 새 색 버퍼를 만들지 않는다. 정점 수와 맞지 않거나 유한한 [0,1] 범위를 벗어난 색은 거부한다.

Base-colour와 normal PNG data URI는 자산 내부의 이미지로 포함하고 완전한 유한 UV0, alpha mode와 normal 강도를 보존한다. normal RGB는 선형 접선 공간으로 해석하며 생략된 강도는 glTF 기본값 1이다. 내보내기 경계는 PNG header와 양수 크기를 검사하며 압축 픽셀의 완전한 해독은 수신 이미지 디코더가 담당한다. 외부 URL, 별도 texture transform, 나머지 texture slot은 이 정적 경로에서 지원하지 않는다. 같은 이미지의 공유는 중복 pixel bytes를 만들지 않으며 모발 mask와 법선도 독립적인 GLB 재생에서 유지한다.

### 편집 화면의 입력과 표시 {#face-spec-editor-view}

<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-editor 인물 선택, 숫자와 슬라이더, 카메라, clay, 파일 입출력과 이력 조작을 화면에 연결한다. -->

화면은 인물 문서와 부위 및 제어의 범위·단위를 표시하고 숫자와 슬라이더를 같은 저작 값에 연결한다. 프리셋, 초기화, 실행 취소, 다시 실행과 문서 불러오기는 편집 트랜잭션을 사용한다. 회전·확대와 clay는 미리보기 상태만 변경한다. 문서 저장은 마지막 유효한 문서를 사용하며 얼굴 export는 그 문서와 함께 commit된 모델을 사용한다. 오류는 사용자에게 표시하고 실패한 입력을 현재 모델로 표시하지 않는다.

미리보기는 가늘고 비스듬한 표면 무늬를 표시할 때 장치가 지원하는 비등방성 텍스처 필터링을 최대16까지 사용하며 미지원 장치는 등방성 필터로 표시한다. 이 장치별 표시 정책은 얼굴 문서, 생성된 기하와 텍스처, 저장하는 GLB bytes를 변경하지 않는다. 같은 장치에서의 표본 품질 향상을 모든 거리의 모발 가시성이나 다른 렌더러의 동일 픽셀 출력으로 해석하지 않는다.

### 실행되지 않는 사진 출처 {#face-spec-provenance}

<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-provenance 미확인 author·license를 발명하지 않는 선택적 사진 출처 레코드를 정한다. -->

얼굴 문서의 선택적 출처는 대표 사진 URL과 byte digest, 저작자, 라이선스, 선택 이유와 품질 한계를 담는다. 알려지지 않거나 사진이 없는 값은 null로 구별한다. 이 레코드의 부재나 변경은 기하 해석, 자원 다운로드 또는 fitting 실행을 유발하지 않는다.

### 검토 상태와 출처 {#face-spec-review}

<!-- @evidence requirements/actors/facial-authoring/contract.md#actor-face-review 인물별 provenance와 각 검증 및 닮음 판정을 서로 독립적으로 기록한다. -->

출처는 대표 원본의 경로, URL, 알려진 저작자와 라이선스 또는 미확인 상태, digest, 선택 이유와 품질 한계를 기록한다. 교체 후보는 원본을 덮어쓰지 않는다. 결과 receipt는 입력 문서와 실제 출력 digest를 연결하며 구성, 재생, 출력 유효성, 캡처 완전성, 직접 열람, 닮음과 잔여 결함을 별도 상태로 둔다. 필수 방향은 정면, 해부학적 좌우 사선과 측면, 후면, 원본 기준 자세와 재질 독립 clay이다. basis 또는 구성 규칙이 바뀌면 이전 검토는 새 출력의 닮음을 보증하지 않는다.
