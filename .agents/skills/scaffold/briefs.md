# Direct briefs

Briefs belong only to a `brief` production. Use `docs/briefs` for one bounded non-narrative audiovisual question that needs no dramatic causality, character choice, or disclosure ladder. Runtime does not decide eligibility.

Use explicitly anchored `H2 delivery -> H3 shot -> H4 observation` units. The H2 states the complete question and initial-to-terminal progression, each H3 allocates one shot's contribution, and each H4 defines the viewing condition and result that can answer or falsify it. Cite settings and only the active model and motion branches actually consumed.

If a viewer must understand why a character chose an action, how one scene caused another, or what a revelation means, stop and migrate the production to `film`. Do not smuggle that authorship into source code or compress a film ladder into one brief.

## Gate

Start at `briefs: "draft"` only after settings and any required design branches are reviewed. Before `evidence`, verify that one document completely allocates the observable contract, each unit answers the common obligations, every observation is falsifiable at its declared condition, and no downstream shot must invent narrative or design meaning. Follow [Evidence staging](evidence-staging.md).
