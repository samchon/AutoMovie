# Reviewing production evidence

Review one declared production surface alone and exhaustively. Do not partition one evidence surface across agents, because overlap, contradiction, and omissions are graph-wide properties.

## Review order

1. Confirm the selected production kind matches the authored structure.
2. Review `config/docs` families with the principle non-overlap test and distinguish principles from distributed obligations.
3. Review production layers in dependency order: research, settings, models, motions, then film or brief prose.
4. Review exact lineage at every anchored unit and source ownership at every exported symbol.
5. Review implementation and tests, then derived records and rendered output where applicable.
6. Run the evidence gate, build, coverage, generated-scaffold compilation, and relevant visual verification.
7. Start a fresh pass from the declared surface. Stop only when a complete pass finds no sound improvement.

An `@evidenceReview` sentence states the concrete relationship checked, not a generic approval. Verify that the host really realizes the cited target, that the target is the narrowest correct unit, and that no sibling target owns the same decision. Copy the fingerprint from the compiler only after that review.

When a principle changes, treat every expired review as a reopened question. Do not restore the old outcome mechanically: inspect the new rule against each governed host.
