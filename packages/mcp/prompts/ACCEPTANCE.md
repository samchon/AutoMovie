# Acceptance Scenarios

`setAcceptanceScenario` makes an observable contract addressable.

Frame criteria name a review-frame id and pass. Event criteria name a semantic event. A frame or event criterion targeting the whole film must also name its owning `shot`; shot-local ids are not assumed globally unique. Metric criteria use a supported deterministic measurement and numeric comparison. The server verifies that references exist; the reviewer decides whether the expectation is artistically and historically adequate.

Required scenarios enter the review and final gates. Write expectations so another agent can falsify them from current evidence. “Looks good” is not an expectation; “the front rank remains legible against smoke in the mask pass” is.

Keep historical assertions in cited research documents and translate only observable consequences into acceptance. The engine cannot prove that a disputed quotation happened; it can prove timing, distance, continuity, visibility, grounding, and deliverable identity.
