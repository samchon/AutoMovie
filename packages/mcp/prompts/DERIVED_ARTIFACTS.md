# Deterministic Derived Artifacts

Use a derived artifact when deterministic work is too expensive for the one-second source sandbox and the exact result should remain project-owned, reviewable, and reproducible. Keep the generator in tracked source, keep every declared input in the generation call, and keep the resulting bytes under `.automovie/derived/`. Do not freeze a megabyte-scale array into TypeScript merely to move the same computation outside the clock.

This path is not asset sourcing. `.automovie/assets.json` records externally acquired or provider-generated bytes, provenance, rights, and consumer permission. `.automovie/derived-artifacts.json` records deterministic project derivation from tracked source and declared project inputs. Never register the same path in both ledgers.

## Opt in explicitly

Select the ledger in `.automovie/manifest.json`:

```json
{
  "derivedArtifactManifest": ".automovie/derived-artifacts.json"
}
```

Generation remains a separate ordinary Node command. Compilation never runs a generator and never repairs a stale result. This preserves the existing one-second budget for each linked module, registration probe, and build call.

## Write one explicit generator script

The product helper owns canonical paths, source normalization, dependency hashing, duplicate execution, encoding checks, and manifest-last atomic publication. The callback receives fresh copies of only the inputs you declared:

```ts
import { generateAutoMovieDerivedArtifact } from "@automovie/mcp";

const result = generateAutoMovieDerivedArtifact({
  root: process.cwd(),
  generator: "scripts/deriveLookup.ts",
  inputs: ["src/data/lookup-source.json"],
  output: ".automovie/derived/lookup.json",
  encoding: "utf8",
  generate: (inputs) => {
    const source = inputs["src/data/lookup-source.json"];
    if (source === undefined) throw new Error("declared input is absent");
    const records = JSON.parse(new TextDecoder().decode(source)) as unknown[];
    return new TextEncoder().encode(JSON.stringify(records) + "\n");
  },
});

console.log(result.changed ? "updated" : "current");
```

Declare the script that actually runs as the `generator`, and keep its derivation inside it. Naming some imported helper instead leaves the running script outside the basis, so changing what it reads, computes, or writes leaves the recorded digest untouched and a stale artifact passes as current.

Keep the callback synchronous and make it depend only on its `inputs` argument and source-local constants. Reading an undeclared file, environment variable, clock, random source, network response, or mutable global hides part of the basis. The helper executes the callback twice against independent copies and refuses publication when the bytes differ, but declared inputs remain the reviewable proof of what the generator was allowed to mean.

The generator path is itself hashed after TypeScript line-ending normalization. Every declared input is hashed as exact bytes. Their ordered, domain-separated closure is the `basisDigest`; the exact generated bytes have a separate `outputDigest`. Do not add a hand-maintained `generatorRevision` or edit either digest.

## Consume only verified bytes

After the explicit script publishes the artifact and ledger, compilation exposes current records through `context.derivedArtifacts`:

```text
const lookup = context.derivedArtifacts[".automovie/derived/lookup.json"];
if (lookup === undefined) throw new Error("lookup artifact is not current");
if (lookup.encoding !== "utf8") throw new Error("lookup must be UTF-8");
const records = JSON.parse(lookup.content) as unknown[];
```

UTF-8 artifacts carry their text directly. Binary artifacts declare `encoding: "base64"` and carry exact bytes as base64. The consumer still owns semantic parsing and validation; a matching digest proves current identity, not that arbitrary bytes are meaningful for that consumer.

## Read refusals literally

- `derived-artifact-manifest-missing` means the selected ledger has not been generated.
- `derived-artifact-manifest-malformed` means its JSON, schema, order, or digest closure is invalid.
- `derived-artifact-path-unsafe` means a manifest, generator, input, output, root, ancestor, or leaf violates canonical physical project ownership.
- `derived-artifact-basis-missing` means the generator or a declared input is absent.
- `derived-artifact-basis-stale` means live generator or input bytes no longer match the recorded basis.
- `derived-artifact-output-missing` means the tracked result is absent.
- `derived-artifact-output-stale` means its exact bytes do not match the recorded output digest.
- `derived-artifact-output-malformed` means an artifact declared as UTF-8 cannot be decoded as UTF-8.
- `derived-artifact-external-collision` means the external asset ledger also claims the deterministic derived namespace.

For every refusal, fix the tracked source or declared inputs and rerun the explicit generation command. Do not edit the ledger or output by hand, loosen the compiler, or move deterministic project derivation into external provenance.

## Size is a separate decision

Empty and large artifacts are valid in this contract. The path removes expensive deterministic derivation from the sandbox; it does not claim that serialization and context transfer are free or unlimited. If a real production needs an output-size or serialization-time limit, measure that boundary and adopt a separate versioned policy instead of inventing an undocumented local cap.
