# Direct briefs

Briefs belong only to a `brief` production. Use `docs/briefs` for one bounded audiovisual question whose complete intent fits one delivery/shot/observation hierarchy. A simple short-form action may qualify; a result that needs independent dramatic causality, character-choice, or disclosure refinement does not. Runtime does not decide eligibility.

Use explicitly anchored `H2 delivery -> H3 shot -> H4 observation` units. The H2 states the complete question and initial-to-terminal progression, each H3 allocates one shot's contribution, and each H4 defines the viewing condition and result that can answer or falsify it. Cite settings and only the active model, space, material, instance, motion, and system branches actually consumed.

If those meanings require decisions separate from the bounded shot observations, stop and migrate the production to `film`. Do not smuggle that authorship into source code or compress a film ladder into one brief.

## Gate

Start at `briefs: "draft"` after settings review. Design branches may proceed in parallel; each newly active reviewed branch adds its foundation targets and reopens affected brief evidence. Before `evidence`, verify that one document completely allocates the observable contract, every H2, H3, and H4 answers the common and brief principle checklists, the H2 population supplies every common and brief-obligation owner, every observation is falsifiable at its declared condition, and no downstream shot must invent narrative or design meaning. Shots still wait for the reviewed source corresponding to every active design branch.

Run [Author process Self-Review](self-review.md) to its clean round before the transition. Follow [Evidence staging](evidence-staging.md).
