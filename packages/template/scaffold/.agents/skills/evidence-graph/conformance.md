# Evidence conformance owner map

The retired `principles/core/common.md#evidence-content-conformance` and `principles/core/source-units.md#source-evidence-content-conformance` targets have no renamed replacement. Semantic truth is a review procedure, not a statement every governed host can prove about its own annotations. Their independent safeguards have these single owners:

| Failure or safeguard | Canonical owner and required response |
| --- | --- |
| Generic, copied, or slotted statement | [Literal semantic pass](../review-verification/semantic-review.md#literal-semantic-pass) exchanges predicates and dependent clauses with the nearest host and target siblings. Rewrite from a literal read, never by synonym substitution. |
| Wrong target or category substitution | The same semantic pass states the exact target predicate and rejects a finding that answers a neighbouring question. |
| Wrong semantic role or host kind | The semantic pass checks actor, object, authority, operation, and configured unit, file, population, lineage, discovery, or exclusion kind. `lint.config.ts` owns mechanically decidable host selection. |
| Unsupported, contradictory, or wrong-event statement | The semantic pass reads the complete host and necessary lineage and requires literal support for the claimed state and consequence. |
| Ambiguous grammar, duplicate attachment, or malformed fingerprint slot | `@automovie/evidence` syntax validation rejects the structural defect before semantic acceptance. |
| Stale fingerprint, target, host, or review snapshot | Evidence lint owns fingerprint and graph freshness. Any changed target, host, population, or semantic sentence requires a new literal read. |
| Invalid path, stage, population, selector, cardinality, or exclusion | The typed production declaration and evidence compiler reject the mechanically false graph. [Diagnostics](staging.md#diagnostics) finds the earliest actual owner instead of weakening the claim. |
| False quotation, locator, notation, or asserted absence | The semantic pass checks the host's own literal rendering. An asserted absence is reread over the exact child-parent relation for a unit-local upstream exclusion or every selected host for a population exclusion. |
| Tool-authored or refreshed semantic prose | [Independent semantic review](../review-verification/semantic-review.md) separates the human judgment from the compiler-issued fingerprint. A tool may locate rows and append a token, but never write or normalize the finding. |
| Evidence rewrite changes authored bytes | Metadata-rewrite verification compares the protected non-evidence projection and exact evidence rows. An unexplained authored-byte change fails before semantic review. |
| Confirmed content or ownership defect | [Diagnostics](staging.md#diagnostics) repairs the earliest owner, then [Self-Review](../review-verification/self-review.md) traces and rereads every affected consequence before evidence work resumes. |

Review loads semantic checks. Diagnostics loads repair routing. Neither repeats the other's complete method. A compiler-clean graph remains subject to semantic review, and semantic truth never excuses malformed structure.
