# Compilation

Compile and execute the production's typed source. [Ownership](../../../README.md#ownership) owns the project layout and file boundary. A library producer returns the declared model, map, or environment directly; film and brief producers additionally realize the selected staging, motion, camera, sound, and timing. Do not introduce a serialized project store between a producer and its consumers.

Read the selected kind, active design and source branches, and exact graph-selected owners before execution. A source export implements its reviewed design address. A helper does not become a design owner merely because its code is under `src`; the evidence declaration selects that relationship.

Keep package and compiler settings in `package.json`. The source compiler checks the complete source program, including command and browser modules. Execute Node entry points with the configured TypeScript runner and load browser code through the viewer's compiled generation. A browser producer must not import Node-only modules at runtime.

Validate the typed result at its consuming package boundary. Preserve identity, ranges, references, deterministic geometry, actor and object motion, camera and event timing, and the declared result population. An invalid input or result must remain a diagnostic rather than being replaced by an empty successful output.

Use the same producer and explicit input values for measurements, preview, and delivery. Record the exact source revision and invocation basis with an observation. A result from earlier source cannot answer for a changed producer, and an output's existence does not establish its currentness.

## A clean compile is not a look

Compilation establishes type and declared structural agreement. It does not establish appearance, natural motion, legible composition, or a completed review.

Open the exact required images, play the required intervals, and examine the complete declared production population under [Review verification](../review-verification/SKILL.md). Preserve missing, failed, unsupported, and unobserved outcomes. A successful command cannot turn any of them into accepted work.

Correct the earliest authored owner, rerun every affected consumer, and renew the observations whose basis changed. Never repair a source defect by editing its rendered output or weakening the selected evidence population.
