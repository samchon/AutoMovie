# Source ownership

The project [Ownership](../../../README.md#ownership) section owns source placement, allowed files, and the source-first execution boundary. Review observations remain in evidence citations and Git rather than a second project ledger.

Author deterministic values and functions under the source branch selected by the reviewed design. A helper can live elsewhere under the same source root without becoming an independent production owner; its calling owner still answers for the result.

Keep derivation in source functions over explicit inputs. Share a producer among preview, measurements, and delivery consumers so they inspect the same geometry, populations, motion, and timing. External acquisition happens before deterministic execution and retains its provenance at the authored owner that adopts it.

A model owns reusable geometry and articulation. Instances own placement and bounded variation. A library owner returns its declared reusable model, map, or environment without inventing a shot or clock. Film and brief source additionally own the staging and time-dependent program their reviewed documents require.

Preserve stable authored identities and source-to-design citations. A source export must not borrow another owner's address or conceal newly invented design facts behind an implementation detail. [Evidence staging](../evidence-graph/staging.md) owns the selected source population and citation relationship.

Keep source execution reproducible from its declared inputs, units, seeds, and source revision. Pass derived values explicitly to consumers. Missing input remains a refusal rather than an approximate cached value.

Examples teach operations and supply no production content. Adapt the required technique into the owning branch and verify it against that branch's actual design.

Never edit a rendered output to repair source. Correct the earliest owner, execute its producer again, and repeat every affected observation under [Review verification](../review-verification/SKILL.md).
