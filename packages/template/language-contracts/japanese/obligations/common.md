```contract-rule
{
  "id": "japanese-population-interference-account",
  "status": "active",
  "safeApplication": "population-distribution",
  "timing": "after the complete selected Japanese-language population exists",
  "sourceIdentity": "campaign-2363-b25-language@8b03cf3b80d205f71d2ba1f5c52c90a02c050b5b"
}
```

一つの層が完成した後、宣言した日本語の変種を流暢に読むレビュー担当者が、証拠コメントを除いた母集団全体を先に読む。場面、話者、圧力、終わり方が異なるのに、翻訳調の節構成、過剰な主語、名詞化、待遇表現、説明骨格が機能なく収束していないか実例ごとに比較し、反復句、制度文書、人物固有の話し方など所有された反復は保存する。

レビュー質問: 異なる素材を機能なく支配する日本語の骨格は何で、どの実例がその判断を立証するか。

出典: [Padmakumar と He によるモデル支援文章の多様性研究](https://arxiv.org/abs/2309.05196); [国立国語研究所](https://www.ninjal.ac.jp/)

## 読者の言語アクセス {#japanese-audience-language-access}

```contract-rule
{
  "id": "japanese-audience-language-access",
  "status": "active",
  "safeApplication": "population-distribution",
  "timing": "after the complete selected Japanese-language population exists",
  "sourceIdentity": "campaign-2363-b25-language@8b03cf3b80d205f71d2ba1f5c52c90a02c050b5b"

```

母集団全体は、説明されない言語切替、専門語、時代語、字幕、引用、翻訳版について、想定読者が意味、出典、状態を識別できるようにしつつ、作品が保存すると決めた差異を消さない。

レビュー質問: どの日本語境界が、想定読者による制作上の決定の理解または出典と状態の識別を妨げているか。

出典: [W3C の言語ネゴシエーション](https://www.w3.org/International/questions/qa-lang-priorities); [W3C TTML2](https://www.w3.org/TR/ttml2/)
