# AutoMovie production contract

Write creative and implementation work in `docs`, `src`, `test`, and declared assets. Do not translate normal code into giant MCP JSON calls.

`src/examples` is reading material, not a library. Each file demonstrates one authoring technique against placeholder geometry, nothing in the production imports it, and no evidence claim covers it. Copy the technique into your own `src/units`, `src/objects`, `src/world`, or `src/formations`, then delete what you have read. Never import from it, and never grow it into a catalogue of finished parts: the models, finishes, and fittings a production needs are its own to author.

Read `AUTOMOVIE_OVERALL`, then the exact guide required by a production tool. Use MCP for actual PNG evidence and evidence-bound review. For offline geometry, load current compiler-owned state through `loadAutoMovieProjectState`, require its freshness to be current, and pass its typed values to pure engine functions.

Run `npm run capture:install` and `npm run capture:doctor` after dependency changes or before the first preview or render. Do not silently fall back to a machine browser; system Chrome or Edge must be selected explicitly in `automovie.config.ts`.

The tracked design records under `.automovie/design` are derived, not hand-kept. `scripts/emitDesign.ts` builds each one from the typed source that owns it and `npm run design` stores it, so that script is this production's code: it imports units, formations, world, and shots by path and states each shot's module and export. Replace those sources and edit that script in the same pass. It writes and never deletes, so a record you stop deriving stays resident and keeps its obligations. `npm run design` refuses while one is there and names its file. Delete that file or derive it. The screenplay index is not a design record and is never named. Read `PRODUCTION_DESIGN` before replacing the starter production, which is one pass and cannot be closed green halfway.

Never edit `generated`; correct its owning source or design and compile. Never mark visual review complete without opening current bundle frames. A design, source, generated, or frame change makes dependent review stale by design.

Open `viewer/inspect.html?shot=<id>` to fly a free camera through a compiled shot when authored framing hides a fault; it prints the eye position so an oddity is reported by coordinate. Open `viewer/subject.html?shot=<id>&subject=<kind>:<id>` to inspect one thing alone; without `?subject=` it lists the shot's spaces and instance sets. Its eye is derived from the subject's content extent rather than its declared cell, and `X` sections the near side. Neither view writes state or substitutes for delivery review. Read `DEBUGGING`. The project write hook also protects `renders`, capture receipts, and `.automovie/productions`; use the command named by its refusal.

Choose exactly one production kind in `lint.config.ts`. A `film` makes a narrative claim through `storylines -> scenarios -> script -> shots -> filmSources`, however short it is. A `brief` makes one bounded non-narrative audiovisual claim through `briefs -> shots -> filmSources`, such as a turntable or motion demonstration. A `library` authors settings, production source, and whichever model or motion design and source branches apply, without shots or film source. Do not choose by runtime, leave an inapplicable active folder empty, or edit evidence populations by hand; select the kind and stages through `createAutoMovieEvidenceConfig`.

Reusable law lives under `config/docs`: authored-document principles are per-file checklists, source principles are covered across the selected export population, and obligations divide distinct responsibilities across a document population. Every H2 rule remains non-overlapping. Production evidence lives under `docs`. Settings say what exists and what it can do, models say how it is represented deterministically, motions say how state changes over time, narrative prose says what the audience understands, production source serializes settings, shot source realizes one local scene, and film source assembles the global edit and auxiliary tracks. Read `EVIDENCE_GRAPH` before changing any layer.

Film prose preserves exact, explicit, ordered, and correctly nested `##` sequence, `###` scene, and `####` beat anchors through storyline, scenario, and script. Brief prose uses explicitly anchored `##` delivery, `###` shot, and `####` observation identities without pretending a non-narrative demonstration has dramatic causality. Each governed source file has its own named exported owner; each exported model class cites exactly one model document, each exported motion function or property cites exactly one motion document, and each exported shot or acceptance symbol cites exactly one script scene or brief shot.

Every layer is explicitly `disabled`, `evidence`, or `review`. A disabled layer has no governed Markdown or TypeScript hosts, while an active layer has at least one; the factory refuses residual and empty populations. Active Markdown files contain explicitly anchored units their graph addresses: H2 everywhere and correctly nested H2/H3/H4 for film or brief ladders. Every active source file has a named exported owner. A child cannot enter `evidence` until every direct parent is in `review`; `review` additionally requires a compiler-issued `@evidenceReview <target> #<digest> <what you checked>` for every acknowledgement. Advance one layer across before going deeper. Read each target and host, write a concrete review statement, and copy the reported digest only after the review; never invent or bulk-apply fingerprints.

`docs/research` is an optional upstream ledger, disabled until you source something. Write one and its rules arrive with it: an identifiable source and used portion, its authority and material uncertainty, and the exact settings, model, motion, narrative, or review decision it constrains. Research must reach `review` before an authored consumer activates, and every active research H2 must be cited by at least one downstream H2 once such a consumer exists. A ledger never fixes what this production is; that is what the owning production layer is for.

Keep exact beat text, `SCN-*` headings, catalogs, continuity claims, and downstream `{ reason, scene, claim? }` evidence synchronized with the screenplay index. Activate its soft lock before the first shot; after lock preserve deleted numbers as `OMITTED` and use alpha insertion ids instead of renumbering.

Register every distributable asset in `.automovie/assets.json` before use. Preserve its source, license, original and current digest, processing chain, and reasoned consumer; external models also declare ingest, LOD, collision, and measurement-proxy decisions. Never invent provenance or license terms.

Keep time in seconds, space in right-handed Y-up meters, and randomness in explicit design seeds. Do not use wall clock, network, process, filesystem, or unseeded randomness inside shot build functions. The project-state reader is a filesystem API and is forbidden inside shot or film build functions; use it only from standalone measurement scripts, tests, and offline diagnostics.
