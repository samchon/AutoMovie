# Settings obligations

These roles must be covered across the settings H2 population. Unlike principles, an inapplicable role may be excluded for the whole population with a concrete production reason.

## Delivery scope {#delivery-scope}

The settings define the exact deliverable boundary, including whether this package is a film, a direct brief, or a reusable model-and-motion library, what it contains, and where it ends.

Review question: what is the last reviewable artifact this production promises to deliver?

Sources: [NASA systems engineering handbook on stakeholder expectations and system boundaries](https://www.nasa.gov/reference/systems-engineering-handbook/)

## Governing aim {#governing-aim}

The settings define the single production promise against which all lower-layer choices are judged, including the audience or operator and the observation that matters most.

Review question: which one sentence resolves a tradeoff between two otherwise valid implementation choices?

Sources: [Jakobson on the dominant that orders the functions of other elements](https://archive.org/details/readingsinrussia0000mate)

## Coordinate and unit convention {#coordinate-unit-convention}

The settings establish repository-relative axes, handedness, world unit, time unit, and any named spatial anchors shared by multiple models or motions.

Review question: where can every layer obtain the same spatial and temporal reference without copying a convention?

Sources: [glTF 2.0 coordinate system and units](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#coordinate-system-and-units); [Web Animations time values](https://www.w3.org/TR/web-animations-1/#time-values)

## Delivery review condition {#delivery-review-condition}

The settings define the output format, baseline frame size or aspect, declared review distance or camera class, and the condition under which the production's governing aim is judged.

Review question: under which reproducible delivery condition must every required observation remain legible?

Sources: [Academy Digital Source Master project](https://www.oscars.org/science-technology/sci-tech-projects/academy-digital-source-master)
