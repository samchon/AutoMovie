# Answer — the answering motion

**Entry state.** The soloist stands with the hand up. The chorus is in order
behind. The gate at the plaza edge is shut.

**Action.** The soloist holds. The chorus answers as one, closing the 2 m its
own document states. Nothing inside the group moves on its own account.

**Exit state.** The chorus has closed that distance and is visibly the
consequence of the exchange. The soloist still holds. The gate is still shut.

The gate is the one thing on this ground that could change, and this production
does not change it. That is a stated limit rather than an oversight: it stands
so the answer has a stake to land near, and opening it is work whoever replaces
this starter takes on — along with the shot that would have to stage it.

The hold before the answer is the beat the whole film turns on. It is stated as
a duration in the script, not here, because here it is only known to be a hold.
