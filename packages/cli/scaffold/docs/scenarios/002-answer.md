# Answer — the answering motion

**Entry state.** The soloist stands with the hand up. The chorus is in order
behind, two metres nearer than it began. The gate at the plaza edge is shut.

**Action.** The soloist holds the raised hand for the whole scene. Nothing on
the ground moves: the group has already closed its distance, and it standing
there is what the cue did.

**Exit state.** The hand is still up and the cue has outlasted the movement it
caused. The chorus stands where the cue left it, visibly the consequence of the
exchange. The gate is still shut.

The gate is the one thing on this ground that could change, and this production
does not change it. That is a stated limit rather than an oversight: it stands
so the answer has a stake to land near, and opening it is work whoever replaces
this starter takes on — along with the shot that would have to stage it.

The hold is the beat the whole film turns on. It is stated as a duration in the
script, not here, because here it is only known to be a hold.
