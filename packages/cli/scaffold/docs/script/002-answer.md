# SCN-002 — The answer

EXT. PLAZA — DAY, CONTINUOUS

The SOLOIST holds the raised hand. The CHORUS stands where the cue brought it,
holding its order, and remains the visible consequence of that exchange rather
than anonymous background. Nothing in the frame moves; the scene is the cue
outlasting the change it caused.

At the far edge of the ground the GATE stands shut on its one hinge. It is the
only thing here that could change and nothing in this film changes it, so it
reads as the stake the answer lands near rather than as the answer itself.

The hand is up from the first frame to the last. Read from the shot contract:
the scene runs 6.0 seconds and its event window closes at 5.0 seconds, so the
cue is held for the whole **6.0 seconds** and is still readable when the window
is sampled.
