# SEQ-ANSWER — The reply

The soloist holds the plaza, and closes the exchange the cue opened.

The cue holds after the rows have closed, proving it changed the plaza rather
than ending as an isolated pose. The sequence exists so the chorus is the
visible consequence of the exchange instead of anonymous background, and it
leaves the group standing where the cue brought it — the state nothing after
this film has to inherit, because there is nothing after it.

The gate at the edge stays shut throughout. It is what the plaza has at stake
and not what answers, and a later production that opens it is adding an event
rather than finishing this one.
