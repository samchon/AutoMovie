# SEQ-ANSWER — The reply

The soloist holds the plaza, and the chorus answers the cue.

The answering gesture proves the cue changed the plaza rather than ending as an
isolated pose. The sequence exists so the chorus is the visible consequence of
the exchange instead of anonymous background, and it leaves the group somewhere
it was not — the state nothing after this film has to inherit, because there is
nothing after it.

The gate at the edge stays shut throughout. It is what the plaza has at stake
and not what answers, and a later production that opens it is adding an event
rather than finishing this one.
