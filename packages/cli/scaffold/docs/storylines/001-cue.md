# Cue — the call

A soloist raises a hand while the chorus behind stays visibly in its rows.

The sequence exists to make the gesture legible as a cue rather than as an
isolated pose, so the rows have to read as rows while it happens. What it leaves
behind is a group that has been addressed and has not yet answered — which is
the only reason the sequence after it has anything to do.
