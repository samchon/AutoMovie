# PLAZA

Open, level ground. Its whole job is to give the raised hand an uninterrupted
background, so it carries no feature that competes with a silhouette.

## Landmarks

`plaza-center`, the point the soloist steps to. Named because a shot contract
has to be able to say where the gesture happened without restating a
coordinate.

## Extent

Large enough that the chorus's rows end inside frame at the film's widest shot.
A plaza that runs past the frame edge stops being a place and becomes a
backdrop.
