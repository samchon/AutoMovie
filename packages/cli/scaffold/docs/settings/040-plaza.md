# PLAZA

## Ground and landmark {#plaza-ground-landmark}

PLAZA is open, level ground whose named point `plaza-center` is the world origin. The ground must extend far enough that the chorus remains visibly contained at the widest delivered composition, but that derived extent belongs to model design once the composition is known. No wall, step, obstacle, or competing landmark is part of this starter.

## Background role {#plaza-background-role}

PLAZA provides a neutral uninterrupted background behind SOLOIST's raised hand and behind the edges of CHORUS. Any added feature that competes with those silhouettes changes the setting and must be authored here before a model or shot uses it.
