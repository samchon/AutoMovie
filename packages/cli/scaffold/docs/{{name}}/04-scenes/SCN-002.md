# SCN-002 — The answer

EXT. PLAZA — DAY, CONTINUOUS

The SOLOIST holds the plaza, then gives the answering motion. The CHORUS
remains the visible consequence of that exchange instead of anonymous
background.

At the far edge of the ground a GATE stands shut on its one hinge. It is the
only thing here that can change, so the answer has somewhere to land.
