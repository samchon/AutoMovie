# MARKER POST

A plain upright that makes one point visible. It is the simplest prop a
production can own: it performs nothing, holds nothing, and means only where it
stands.

## Silhouette

One vertical, no wider across than a tenth of its own height, so it reads as a
mark rather than as a body. Anything thicker stops marking the point and starts
competing with whatever the frame is about.

## Scale

0.9 m, half the production's reference human scale. Waist height on the
reference figure is the tallest a mark can be and still stay clear of a head, a
raised arm, and anything carried above the waist.

## Colour

One flat neutral tone. The post is read by where it stands, so it carries a
single material colour and no hue that would pull the eye off the subject.

## Use

A production places one post at each point it needs marked and gives that post
the point's coordinates; the post never chooses where it stands. It holds that
place for the whole shot, claims no capability, and is never made to perform: a
mark that moves has stopped being a mark. Two marked points are two posts, never
one post widened to cover both.
